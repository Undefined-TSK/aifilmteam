# 角色设计师 Agent 流程图

> 对应 Agent：角色设计师
> 用途：检查角色设计师的工作流是否完整、判断节点是否覆盖关键决策点、人工兜底是否到位

```mermaid
flowchart TD
    A[收到编剧角色描述] --> B{描述明确?}
    B -- 否 --> C[追问补充性格和身份]
    C --> A
    B -- 是 --> D[复述: 性格翻译成外貌特征]
    D --> E{编剧确认?}
    E -- 否 --> D
    E -- 是 --> F[搜索参考图]
    F --> G[确定特征关键词+角色色板]
    G --> H{色板与场景冲突?}
    H -- 是 --> I[调整角色配色]
    I --> J
    H -- 否 --> J[调ComfyUI生成正面定调图]
    J --> K{生成成功?}
    K -- 否 --> L{重试过1次?}
    L -- 否 --> J
    L -- 是 --> M[人工兜底: 报告艺术总监]
    K -- 是 --> N[自检: 特征体现+辨识度+色板]
    N --> O{自检通过?}
    O -- 否 --> P{重试少于3次?}
    P -- 是 --> G
    P -- 否 --> M
    O -- 是 --> Q[提交艺术总监定调审核]
    Q --> R{艺术总监通过?}
    R -- 否 --> S{退回少于3次?}
    S -- 是 --> T[按修改方向调参重生成]
    T --> J
    S -- 否 --> U[人工兜底: 请艺术总监给明确方向]
    R -- 是 --> V[生成三视图+表情集]
    V --> W{三视图一致?}
    W -- 否 --> X{重生成少于3次?}
    X -- 是 --> V
    X -- 否 --> Y[人工兜底: 请艺术总监判断是否降级单视图]
    W -- 是 --> Z[锁定K13+写character_lock JSON]
    Z --> AA{所有角色完成?}
    AA -- 否 --> F
    AA -- 是 --> AB[汇总成果向艺术总监汇报]
```
