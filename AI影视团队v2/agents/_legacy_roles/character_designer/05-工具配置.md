## 三、工具详情

### 3.1 ComfyUI图像生成

**类型：** 内置Skill（`creative/comfyui`）
**服务地址：** `http://127.0.0.1:8188`
**GPU：** NVIDIA RTX 5070 Laptop（12GB VRAM）
**模型：** SDXL Base 1.0（`sd_xl_base_1.0.safetensors`）

**角色设计师使用的工作流：**
- `sdxl_txt2img.json` — SDXL文生图，定调图/三视图/表情集（1024x1024）
- `sdxl_img2img.json` — 图生图，基于定调图延展三视图（保持一致性）

**prompt构建规则：**
- 基础prompt = 特征关键词清单 + 角色描述 + 画面风格 + 视角指令
- 三视图prompt加视角指令：`front view / side view / back view, character sheet`
- 表情集prompt加表情指令：`neutral / happy / sad / surprised expression`
- 负面prompt = 标准负面词 + 场景主色（避免撞色时加入）
- 采样步数：20-30步（定调图20步，三视图30步）
- CFG：7-8
- **一致性关键（2026-09-26实测修正）：图生图转体失败** — img2img denoise 0.6 下锚点构图主导，side/back输出仍是正面；**有效策略 = 纯文生图 + 视图短语前置 + 剥离姿势/构图锚词（portrait/sitting等）+ 身份由prompt_injection承载**（先例：林小雨v2-v5四个不同seed同prompt形象稳定）。详见3.6 three_view_client.py

### 3.5 character_lock写入工具

**脚本路径：** `D:\ai_film_projects\tools\character_lock_writer.py`（已创建，参照scene_lock_writer.py，write/read/list/remove四命令，测试通过）
**数据格式：** JSON文件
**存储位置：** `项目路径/character_lock/{角色名}.json`

**功能列表：**

| 命令 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `write {角色名} {参数JSON}` | 写入角色锁定文件 | 角色名+特征+色板+prompt_injection | JSON: path + status |
| `read {角色名}` | 读取角色锁定文件 | 角色名 | JSON: content |
| `list` | 列出所有已锁定角色 | 无 | JSON: characters列表 |

**character_lock JSON结构：**
```json
{
  "character_name": "林小雨",
  "feature_keywords": ["米色风衣", "黑色长发", "圆框眼镜", "帆布包"],
  "color_palette": {
    "primary": "#d4c5a9",
    "secondary": "#2b2b2b",
    "accent": "#8b7355"
  },
  "prompt_injection": "young woman, beige trench coat, long black hair, round glasses, canvas bag",
  "views": ["front", "side", "back"],
  "expression_set": ["neutral", "happy", "sad"],
  "concept_art_path": "assets/characters/林小雨/v1.png",
  "locked_version_uuid": "b3c8e2f1",
  "locked_at": "2026-09-25T10:30:00"
}
```

**下游使用方式：**
- 分镜师：读取character_lock，将prompt_injection注入分镜prompt保证角色一致
- 动画师：读取character_lock，将特征关键词注入动画生成参数
- 场景设计师：读取color_palette，避免场景与角色撞色

### 3.6 三视图客户端（2026-09-26新增，实测通过）

**脚本路径：** `D:\ai_film_projects\tools\three_view_client.py`
**策略：** 锚点prompt剥离姿势锚词 + 视图短语前置 + 新seed txt2img，身份由prompt_injection承载

**命令：**
```bash
python three_view_client.py generate <project> --character 林小雨 [--views side,back]
    [--seed N] [--strip "锚词1,锚词2"] [--reinforce "强化短语"] [--negative-extra "负面词"]
python three_view_client.py commit <project> --character 林小雨
```

**流程：** `generate`（出图+扣费10点/视图，meta合并式支持分轮补视图）→ 自检（跑形判断）→ `commit`（写回character_lock的views/three_view_paths）→ K13 lock

**关键参数：**
| 参数 | 用途 | 实测案例 |
|------|------|---------|
| `--strip` | 额外剥离锚词（默认已含 cinematic portrait/sitting in a cardboard box/portrait） | 林小雨back剥离 detailed face（该词对抗遮脸） |
| `--reinforce` | 特征强化短语，注入视图短语之后的高权重位 | 林小雨发型漂移（盘发）时注入 "short dark bob haircut, chin-length dark hair" |
| `--negative-extra` | 附加负面词 | 林小雨加 "updo, bun, long hair" 压制盘发先验 |
| `--seed` | 同轮各视图共用；同seed会锁死原构图，默认随机新seed | 小白side/back共用 seed 1234792641 成套 |

**雨夜寻猫实测记录：**
- 小白：side/back 一次通过（白毛/绿眼/湿毛保持，转体正确），seed 1234792641
- 林小雨：side 需发型强化（盘发→bob）；back 3次通过（第3次 = 新seed + walking away from camera 线索 + 剥离 detailed face + 负面词 profile/looking back），seed 2984714034
- 踩坑链：img2img(denoise 0.6)不转体 → 同seed+末尾追加短语权重不足 → 视图短语前置+剥锚词+新seed 成立
