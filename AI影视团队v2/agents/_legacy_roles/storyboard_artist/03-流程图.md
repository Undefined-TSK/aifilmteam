# 分镜师 Agent 流程图

> 对应 Agent：分镜师
> 用途：检查分镜师的工作流是否完整、判断节点是否覆盖关键决策点、人工兜底是否到位

```mermaid
flowchart TD
    A[收到剧本审核通过通知] --> B[读场次清单+复述情绪节奏意图]
    B --> C{理解确认?}
    C -- 否 --> B
    C -- 是 --> D{每场scene_lock+出场角色character_lock齐全?}
    D -- 否 --> E["@制片人催设计岗(只做镜头表不生成图)"]
    E --> F[逐场拆镜: 每场2-4镜五要素]
    D -- 是 --> G[web_search搜镜头语言参考]
    G --> F
    E -.锁到位.-> D
    F --> H[自查分镜铁律: 景别变化+轴线+节奏+时长]
    H --> I{铁律四项全过?}
    I -- 否 --> F
    I -- 是 --> J[构建每镜prompt: lock自动注入]
    J --> K{character_lock+scene_lock都注入?}
    K -- 否 --> J
    K -- 是 --> L[预算check]
    L --> M{预算够?}
    M -- 否 --> N["@制片人(预算不足)"]
    M -- 是 --> O[ComfyUI生成关键镜头分镜图 16:9]
    O --> P[预算spend]
    P --> Q{分镜图与镜头表一致+特征体现?}
    Q -- 否 --> R{重生成少于2次?}
    R -- 是 --> O
    R -- 否 --> S[人工兜底: 艺术总监判定或角色设计师出参考]
    S --> T
    Q -- 是 --> T[提交艺术总监审核: 分镜表+分镜图]
    T --> U{通过?}
    U -- 否 --> V{同场次退回少于2次?}
    V -- 是 --> W[按第几镜+问题+方向改对应镜头]
    W --> F
    V -- 否 --> X[人工兜底: 艺术总监给明确方向或老板介入]
    U -- 是 --> Y[锁定K13 storyboard]
    Y --> Z{全场次锁定?}
    Z -- 否 --> T
    Z -- 是 --> AA[分镜表JSON+MD落盘storyboard/]
    AA --> AB[handoff交动画师: 完整镜头指令表]
