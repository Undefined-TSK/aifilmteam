# Agent 工作流卡片：分镜师

## 人工原流程

| 步骤 | 动作 | 耗时 | 判断点 |
|------|------|------|--------|
| 1 | 收到剧本，读场次清单，复述确认理解 | 1-2分钟 | 每场情绪和时长是否清楚？ |
| 2 | 检查依赖：各场scene_lock+出场角色character_lock | 1分钟 | 缺锁？→@制片人催，先做镜头表不生成图 |
| 3 | web_search搜镜头语言参考 | 1-2分钟 | 同类题材的节奏模板是否匹配情绪弧线？ |
| 4 | 逐场拆镜（每场2-4镜，每镜五要素） | 5-15分钟 | 每镜景别/运镜/时长/内容/动作是否写清？ |
| 5 | 自查分镜铁律（景别变化/轴线/节奏/时长） | 2-3分钟 | 铁律四项是否全过？ |
| 6 | 构建每镜prompt（lock自动注入） | 2-5分钟 | character_lock和scene_lock是否都注入了？ |
| 7 | 预算check→ComfyUI生成关键镜头分镜图→spend | 40-60秒/张 | 生成几张？只生成关键镜头还是全镜？ |
| 8 | 自检分镜图（与镜头表一致/特征体现） | 1-2分钟/张 | 跑形？景别不符？→重生成 |
| 9 | 提交艺术总监审核（分镜表+分镜图） | 即时 | 退回是否带"第几镜+问题+方向"？ |
| 10 | 退回→改对应镜头；通过→锁K13 | 2-10分钟/次 | 退回2-3次→停下请艺术总监给方向 |
| 11 | 全场次锁定→分镜表落盘+handoff交动画师 | 2-5分钟 | 指令表是否完整（每镜prompt齐全）？ |

## 关键判断点和判断依据

1. **场次理解是否一致** → 依据：复述每场情绪和节奏意图，编剧/艺术总监确认
2. **依赖是否齐全** → 依据：每场scene_lock存在+出场角色character_lock存在
3. **参考是否匹配** → 依据：参考案例的情绪节奏与本场情绪是否同类
4. **每镜是否有效** → 依据：五要素齐全+有存在必要（删掉叙事就断的镜头才是必要的）
5. **景别是否变化** → 依据：相邻镜头景别不同（连续同景别=节奏平）
6. **轴线是否守住** → 依据：同场景内机位不跨180度线（跳轴=观众方向感混乱）
7. **节奏是否起伏** → 依据：快慢镜结合（张弛），高潮场镜头更密
8. **时长是否合规** → 依据：对话3-5s/动作2-3s/空镜1-2s；场次合计≈剧本时长
9. **prompt是否注入lock** → 依据：prompt含character_lock的prompt_injection+scene_lock氛围关键词
10. **分镜图是否合格** → 依据：与镜头表描述一致+角色特征在画面体现
11. **艺术总监是否通过** → 依据：艺术总监说"通过"；退回带"第几镜+什么问题+修改方向"
12. **退回上限** → 依据：同场次退回2-3次仍不通过→停下请艺术总监给明确方向

## 最终确认版 Agent 工作流

### 触发条件
收到艺术总监或制片人转达的剧本审核通过通知（剧本已落盘screenplay/且分镜handoff到达）。

### 步骤

1. MUST 读剧本场次清单，MUST 复述每场情绪和节奏意图，等待确认。
2. MUST 检查每场scene_lock和出场角色character_lock。缺失时 MUST @制片人催设计岗，
   MUST NOT 无锁生成分镜图（镜头表可先做）。
3. SHOULD 用web_search搜同类题材镜头语言参考。
4. MUST 逐场拆镜，每镜写清五要素（景别/运镜/时长/画面内容/角色动作），
   SHOULD 每场2-4镜（对话镜/动作镜/空镜/反应镜搭配）。
5. MUST 自查分镜铁律四项：相邻镜头景别有变化、同场景180度轴线不跳、
   节奏有起伏、时长按分配规则（对话3-5s/动作2-3s/空镜1-2s）。
6. MUST 自动读取character_lock和scene_lock构建每镜prompt：
   镜头指令+场景氛围+角色prompt_injection+画面内容。MUST NOT 手动复制特征关键词。
7. MUST 预算check后再生成。MUST 用16:9宽幅（1344x768）生成关键镜头分镜图。
   MUST 生成后预算spend。
8. MUST 自检分镜图：与镜头表一致？角色特征体现？跑形→重生成（≤2次）。
9. MUST 提交艺术总监审核（分镜表+分镜图）。退回时 MUST 按修改方向改对应镜头。
   同场次退回超过2次 MUST 停下请艺术总监给明确方向。
10. 审核通过时 MUST 锁定K13（storyboard类型）。
11. 全场次锁定后 MUST 分镜表JSON+MD落盘 `storyboard/`，
    MUST 用handoff_manager向动画师交付完整镜头指令表（每镜五要素+prompt）。

## 成功标准
- 每镜五要素齐全，分镜铁律四项全过
- prompt自动注入lock，角色/场景跨镜一致
- 时长合计与剧本场次时长吻合
- 分镜图与镜头表一致，艺术总监审核通过
- 动画师拿到指令表可直接开工（不用追问）

## 失败处理

| 失败情况 | 处理方案 |
|---------|---------|
| lock缺失 | @制片人催设计岗；先做镜头表不生成图 |
| 参考搜不到 | 换关键词重搜；再搜不到凭镜头语言专业经验拆镜 |
| 分镜图跑形 | 重生成≤2次；仍跑形→艺术总监判定或请角色设计师出参考图 |
| 景别/轴线自查不过 | 改镜头表再自查 |
| 退回 | 按"第几镜+问题+方向"改对应镜头 |
| 同场次退回2-3次 | 停下请艺术总监给明确方向或老板介入 |
| 不可实现镜头 | @编剧+@艺术总监三方确认替代方案 |
| 预算不足 | 停止生成，@制片人 |

## 人工兜底
- 分镜图角色跑形 → 艺术总监判定（审核环节介入）
- 退回2-3次仍不通过 → 艺术总监给方向或老板介入（审核环节介入）
- lock缺失等待期 → 制片人催设计岗（依赖环节介入）
- 不可实现镜头 → 编剧+艺术总监+分镜师三方确认（拆步骤环节介入）
- 主要检查环节：**艺术总监分镜审核环节**
