# 关卡 5：工具配置 — 分镜师Agent

## 一、概述

本文件记录分镜师Agent所需全部工具的配置与集成。分镜师负责剧本→镜头序列的翻译、lock注入生成分镜图、K13锁定和动画师交接，需要图像生成、lock读取、版本管理和交接工具。

**配置原则：** 工具轻量化、数据文件化、复用优先。分镜师全部复用已有工具（ComfyUI、K13、预算、character_lock/scene_lock读取、web_search、file、handoff_manager），无新增脚本。核心是分镜表JSON结构和prompt注入公式。

## 三、工具详情

### 3.1 ComfyUI分镜图生成（复用）

**类型：** 内置Skill（`creative/comfyui`）
**服务地址：** `http://127.0.0.1:8188`
**模型：** SDXL Base 1.0

**分镜师使用规范：**
- 分辨率：**1344x768（16:9）**——SDXL原生分辨率桶，分镜节点闭环已验证的默认值
- 用途：关键镜头分镜参考图（非全镜生成——每场挑1-2个关键镜头出图，其余靠镜头表文字描述）
- prompt结构见3.4注入公式

### 3.2 K13版本树（复用）

**脚本路径：** `D:\ai_film_projects\tools\k13_version_tree.py`

| 命令 | 用途 |
|------|------|
| `lock storyboard {资产名} {图片路径} {参数JSON}` | 锁定分镜图版本 |
| `history {资产名}` | 查看分镜版本历史 |
| `list` | 查看所有已锁定版本 |

**锁定参数JSON：**
```json
{
  "type": "storyboard",
  "name": "分镜1-1",
  "prompt": "完整生成prompt（含lock注入）",
  "seed": 1234567890,
  "steps": 25,
  "cfg": 7.5,
  "shot_info": {"shot_type": "MS", "camera_move": "dolly in", "duration_sec": 4}
}
```

### 3.3 lock读取（复用）

| 脚本 | 命令 | 注入内容 |
|------|------|---------|
| `character_lock_writer.py` | `read {项目路径} {角色名}` | prompt_injection字段→角色特征 |
| `scene_lock_writer.py` | `read {项目路径} {场景名}` | mood/lighting/color_palette→场景氛围 |

**铁律：** MUST自动读取注入，MUST NOT手动复制特征关键词（手动复制=跨镜不一致源头）。

### 3.4 prompt注入公式（核心规范）

```
分镜prompt = {镜头指令} + {scene_lock氛围} + {character_lock.prompt_injection} + {画面内容} + {风格后缀}
```

**各段来源与示例（雨夜寻猫·第3场巷口重逢）：**

| 段 | 来源 | 示例 |
|----|------|------|
| 镜头指令 | 分镜师自己写 | `cinematic storyboard frame, medium shot` |
| scene_lock氛围 | scene_lock/雨夜巷口.json | `warm streetlight glow, wet alley, rainy night` |
| character_lock注入 | character_lock/林小雨.json的prompt_injection | `young Chinese woman, beige trench coat, short dark hair` |
| 画面内容 | 镜头表description | `kneeling down reaching into cardboard box, white kitten with green eyes` |
| 风格后缀 | 导演意图文档 | `35mm film, cinematic lighting, high quality` |

**多角色镜头：** 每个出场角色的prompt_injection都注入，按主次排序。

### 3.5 分镜表JSON结构（核心规范）

**存储位置：** `项目路径/storyboard/{项目名}_分镜表_v{N}.json` + 同名`.md`

```json
{
  "project": "雨夜寻猫",
  "version": 1,
  "based_on_screenplay": "screenplay/雨夜寻猫_剧本_v1.json",
  "total_duration_sec": 80,
  "scenes": [
    {
      "scene_no": 3,
      "location": "雨夜巷口",
      "scene_emotion": "微光希望·重逢",
      "shots": [
        {
          "shot_no": "3-1",
          "shot_type": "MS",
          "camera_move": "static",
          "duration_sec": 4,
          "description": "林小雨停在窄巷口喘气，伞沿滴水，巷口纸箱入画",
          "character_action": "林小雨停步张望",
          "emotion": "期待",
          "locks_used": ["scene_lock/雨夜巷口.json", "character_lock/林小雨.json"],
          "prompt": "（按3.4公式拼接的完整prompt）",
          "reference_image": "assets/storyboards/分镜3-1_v1.png"
        }
      ]
    }
  ]
}
```

**景别术语表：**

| 缩写 | 中文 | 用途 |
|------|------|------|
| ECU | 大特写 | 情绪爆点 |
| CU | 特写 | 情绪/反应 |
| MS | 中景 | 对话 |
| FS | 全景 | 人物全身动作 |
| WS | 远景 | 环境/气氛（雨夜寻猫第4场归途=已锁分镜01） |
| LS | 大远景 | 建立/收尾 |

**运镜术语表：** `static`（固定）/ `dolly in`（推近）/ `dolly out`（拉远）/ `pan left/right`（左右摇）/ `tracking`（跟拍）/ `crane up`（升）/ `handheld`（手持感）

**时长分配铁律：** 对话镜3-5s / 动作镜2-3s / 空镜1-2s；场次镜头时长合计≈剧本场次duration_sec。

### 3.6 预算管理（复用）

| 命令 | 分镜师用途 |
|------|-----------|
| `check {金额}` | 生成前检查 |
| `spend {金额} {描述} {资产名}` | 生成后记录 |

**预算规则：** 每场1-2张关键镜头，全片按4场×2张=8张预备；10点/张约80点。余额<20%提醒制片人。

### 3.7 交接交付（复用）

**分镜师使用的命令：**

| 命令 | 用途 |
|------|------|
| `create {项目路径} storyboard_artist animator {任务名} {背景} {交付物JSON} {下游任务}` | 交付镜头指令表给动画师 |

**交接内容：** 分镜表JSON路径+分镜图目录。动画师按每镜五要素+prompt直接生成视频。
