## 二、TTS配置（edge-tts）

**已搜索验证**：Python库6.0.0仍活跃，免费无API限制，无需Edge浏览器/Azure key，支持中文neural voices+SRT字幕输出。

**安装：**
```powershell
pip install edge-tts
```

**音色候选（林小雨：18岁安静内向年轻女声）：**

| 候选 | 音色代码 | 特点 |
|------|---------|------|
| A | zh-CN-XiaoyiNeural | 年轻、偏活泼 |
| B | zh-CN-XiaoxiaoNeural | 标准女声、通用 |
| C | zh-CN-XiaohanNeural | 温柔、偏暖 |

> 实战时三选一试听（生成同一句"小白——小白？"对比），定稿后全片统一。

**逐句生成命令模板：**
```powershell
edge-tts --voice zh-CN-XiaoyiNeural --rate=+5% --text "小白——小白？" --write-media audio/dialogue/2-2.mp3
```

**情绪调参基准：**

| 情绪 | rate | pitch | 备注 |
|------|------|-------|------|
| 平静疑问 | -5% | 0 | 慢半拍 |
| 焦虑急促 | +10% | +2Hz | 略升调 |
| 呼喊 | +5% | +5Hz | 音量靠剪辑层 |
| 温柔哽咽 | -10% | -2Hz | 慢+降调 |
