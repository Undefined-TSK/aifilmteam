# 音效工程师 工作流卡片

> 版本 v1.0 | 2026-09-25 | 输入：剧本+分镜表 → 输出：四音轨+清单

## 人工流程（8步）

| 步 | 动作 | 判断点 |
|----|------|--------|
| 1 | 读剧本对白清单（10句）+分镜表时长轴（80s） | 对白归属镜号明确？情绪标注齐？ |
| 2 | 设计四轨总表：环境/动效/对白/BGM | 每场环境音定调？动效逐镜列？ |
| 3 | TTS音色选型：试听2-3个候选→定1个 | 年轻女声？安静内向气质？→不确定问艺术总监 |
| 4 | 对白逐句生成+自检 | 清晰？语速（对话镜3-5s内说完）？情绪（焦虑句不甜美）？ |
| 5 | 环境音/动效/BGM素材获取（CC0库） | 素材时长覆盖场次？授权合规？ |
| 6 | 音画对齐自检 | 对白时长≤镜时长-1s（呼吸感）？BGM段落与场次边界对齐？ |
| 7 | 音轨清单落盘JSON+MD | 每条含镜号/轨别/文件/时长/淡入淡出 |
| 8 | handoff交付剪辑师 | 四轨素材+清单齐？ |

## 四轨设计规范

### ① 环境音（ambience，打底轨）
| 场 | 素材 | 覆盖 | 淡入淡出 |
|----|------|------|---------|
| 1出租屋 | 室内雨声（闷）+挂钟滴答 | 全场15s | 开场3s淡入 |
| 2街道 | 街道雨声（开）+远处车流 | 全场20s | 转场交叉淡化 |
| 3巷口 | 巷内雨声（空旷回声感） | 全场25s | 猫叫前压低 |
| 4归途 | 雨声渐弱 | 全场20s | 结尾5s淡出 |

### ② 动效音（SFX，突出轨）
| 镜 | 音效 | 备注 |
|----|------|------|
| 1-1 | 纸张翻动+雨声穿窗 | 微弱 |
| 1-3 | 椅子刮地+布料抓起 | 急促 |
| 1-4 | 开门+关门+脚步远去 | 三连 |
| 2-1~2-5 | 雨靴踩水洼×N+呼吸 | 节奏随走 |
| 3-1 | 伞收起滴水 | 静→滴 |
| 3-2 | 微弱猫叫（关键） | 声音先于画面 |
| 3-3 | 纸箱窸窣 | 轻 |
| 3-4~3-5 | 布料摩擦+小猫咕噜 | 温暖 |
| 4-2 | 猫叫（应答感） | 呼应3-2 |

### ③ 对白（dialogue，主导轨）
| 镜 | 台词 | 情绪 | 时长上限 |
|----|------|------|---------|
| 1-1 | ……小白？ | 平静疑问 | 2s |
| 1-3 | 窗没关……它肯定出去了。 | 焦虑 | 3s |
| 1-4 | 等我，我马上回来。 | 决然 | 3s |
| 2-2 | 小白——小白？ | 焦虑呼喊 | 3s |
| 2-4 | 不吓你，我们回家。 | 失落轻哄 | 3s |
| 3-2 | 是小白的声音。 | 惊喜 | 2s |
| 3-4 | 找到你了。 | 释然 | 2s |
| 3-5 | 吓死我了……走，回家。 | 温柔哽咽 | 4s |

### ④ BGM（bgm，情绪衬底轨）
| 段 | 情绪 | 乐器建议 | 边界 |
|----|------|---------|------|
| 第1场 | 平静→惊变 | 钢琴单音→骤停 | 惊变点静默1s |
| 第2场 | 焦虑寻索 | 钢琴急促+弦乐铺底 | 全场 |
| 第3场 | 希望重现 | 钢琴转暖+光感音色 | 3-3绿眼亮起时进主题 |
| 第4场 | 温暖释然 | 主题完整呈现→渐弱 | 结尾随雨声淡出 |

## Agent工作流（MUST/SHOULD）

### MUST
1. TTS音色全片统一（定音色后不许换）
2. 每条音轨有时码（镜号+时长）
3. 素材授权合规（CC0/免费商用），清单标注来源
4. 对白时长≤镜时长-1s

### SHOULD
1. BGM主题旋律第3场首次出现第4场完整呈现（前后呼应）
2. 3-2猫叫"声音先于画面"（观众和林小雨同时听见）
3. 交付前用session_search查素材复用机会
