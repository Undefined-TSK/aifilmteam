## 三、工具详情

### 3.1 ComfyUI图像生成

**类型：** 内置Skill（`creative/comfyui`）
**服务地址：** `http://127.0.0.1:8188`
**GPU：** NVIDIA RTX 5070 Laptop（12GB VRAM）
**模型：** SDXL Base 1.0（`sd_xl_base_1.0.safetensors`）

**场景设计师使用的工作流：**
- `sdxl_txt2img.json` — SDXL文生图，场景概念图（1024x1024或1344x768）
- `sdxl_img2img.json` — 图生图，基于参考图风格迁移
- `upscale_4x.json` — 4倍超分辨率，用于最终交付

**prompt构建规则：**
- 基础prompt = 氛围关键词 + 光影方向 + 场景描述 + 画面风格
- 负面prompt = 标准负面词 + 角色主色（避免色彩冲突时加入）
- 采样步数：20-30步（概念图20步，精细版30步）
- CFG：7-8

### 3.4 预算管理（复用）

**脚本路径：** `D:\ai_film_projects\tools\budget_manager.py`

### 3.5 scene_lock写入工具

**脚本路径：** `D:\ai_film_projects\tools\scene_lock_writer.py`
**数据格式：** JSON文件
**存储位置：** `项目路径/scene_lock/{场景名}.json`

**功能列表：**

| 命令 | 功能 | 输入 | 输出 |
|------|------|------|------|
| `write {场景名} {参数JSON}` | 写入场景锁定文件 | 场景名+氛围+光影+色板 | JSON: path + status |
| `read {场景名}` | 读取场景锁定文件 | 场景名 | JSON: content |
| `list` | 列出所有已锁定场景 | 无 | JSON: scenes列表 |

**scene_lock JSON结构：**
```json
{
  "scene_name": "竹林晨雾",
  "atmosphere_keywords": ["清冷", "孤寂", "薄雾"],
  "lighting_direction": "逆光侧光",
  "color_palette": {
    "primary": "#4a6b5a",
    "secondary": "#8b9b8e",
    "accent": "#d4dcd5"
  },
  "memory_point": "薄雾中的石板小路",
  "concept_art_path": "assets/scenes/竹林晨雾/v1.png",
  "locked_version_uuid": "a2448fb1",
  "locked_at": "2026-08-22T14:30:00"
}
```

**下游使用方式：**
- 分镜师：读取scene_lock，将氛围关键词注入分镜prompt
- 动画师：读取scene_lock，将光影方向注入动画生成参数
