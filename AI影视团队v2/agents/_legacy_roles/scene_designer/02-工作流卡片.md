# Agent 工作流卡片：场景设计师

## 人工原流程

| 步骤 | 动作 | 耗时 | 判断点 |
|------|------|------|--------|
| 1 | 收到编剧发来的场景描述（地点、时间、情绪） | 即时 | 描述是否够具体？只有"好看的景"就追问 |
| 2 | 复述理解，等编剧确认一致 | 即时 | 编剧说"对"才继续；纠正了就重新理解 |
| 3 | 用浏览器搜索参考图（电影截图、概念设计、光影案例） | 1-2分钟 | 参考图方向是否匹配场景情绪？搜不到就换关键词 |
| 4 | 确定氛围关键词、光影方向、主色方案 | 1分钟 | 和角色色板冲突？冲突→调整场景配色 |
| 5 | 调ComfyUI生成第一版场景概念图 | 30秒-2分钟 | 生成成功？失败→重试1次 |
| 6 | 自检：画面匹配描述？记忆点有没有？色板冲突不？ | 即时 | 不达标→调参；达标→进审核 |
| 7 | 提交艺术总监审核，附参考图+氛围说明 | 即时 | （艺术总监判断）通过→锁定；退回→改 |
| 8 | 退回→按修改方向调参重生成；通过→锁定K13+写scene_lock | 30秒-2分钟/次 | 退回2-3次→停下让艺术总监或老板介入 |
| 9 | 所有场景锁定后，汇总成果向艺术总监汇报 | 即时 | 全部完成？有遗漏？汇报简短文本 |

## 关键判断点和判断依据

1. **场景描述是否明确** → 依据：是否包含具体地点+情绪（如"竹林晨雾，清冷孤寂"vs"一个好看的景"）
2. **理解是否一致** → 依据：编剧复述确认后说"对"才继续
3. **参考图是否匹配** → 依据：搜到的图是否传达了场景所需的情绪和氛围
4. **色板是否冲突** → 依据：场景主色与角色主色是否在色环上过于接近（<30度色相差）
5. **生成是否成功** → 依据：ComfyUI正常返回图片，无报错
6. **自检是否通过** → 依据：画面匹配描述+有记忆点+色板不冲突
7. **艺术总监是否通过** → 依据：艺术总监说"通过"或"锁定"；退回必须带修改方向
8. **退回上限** → 依据：同一场景退回2-3次仍不通过，停下请艺术总监给明确方向或老板介入
9. **是否全部完成** → 依据：场景清单中每个场景都已锁定

## 最终确认版 Agent 工作流

### 触发条件
收到编剧通过对话界面或任务系统发来的场景描述。

### 步骤

1. MUST 确认收到场景描述。如果描述模糊（缺少具体地点或情绪），MUST 追问编剧"请补充场景地点和氛围方向"。
2. MUST 复述场景理解（地点+时间+情绪+关键道具），等待编剧确认。编剧纠正后 MUST 重新理解并再次复述。
3. SHOULD 用浏览器搜索参考图（电影截图、概念设计、光影案例）。SHOULD 搜2-3组不同关键词拓宽方向。
4. MUST 确定氛围关键词、光影方向、主色方案。MUST 检查与角色色板是否冲突，冲突时 MUST 调整场景配色。
5. MUST 调用ComfyUI生成场景概念图。生成前 MUST 检查预算余额。
6. MUST 自检：画面是否匹配场景描述？是否有记忆点视觉元素？色板是否与角色冲突？
7. MUST 提交艺术总监审核，附参考图和氛围说明。MUST 使用简短文本（不超过100字）。
8. 艺术总监退回时 MUST 按修改方向调参重新生成。退回超过2次仍不通过时 MUST 停下请艺术总监给明确方向。
9. 艺术总监通过时 MUST 锁定版本到K13版本树，MUST 写入 `scene_lock/{场景名}.json`。
10. 所有场景锁定后 MUST 汇总成果向艺术总监汇报，MUST 使用简短文本格式。

## 成功标准
- 所有场景概念图按编剧描述生成完成
- 每个场景经艺术总监审核通过并锁定到K13
- scene_lock JSON 已写入，下游可自动获取
- 每个场景有至少1个记忆点视觉元素
- 色板与角色不冲突
- 未超出预算

## 失败处理

| 失败情况 | 处理方案 |
|---------|---------|
| 场景描述模糊 | 追问编剧直到明确 |
| 参考图搜不到 | 换关键词重搜；再搜不到用文字描述直接生成 |
| ComfyUI生成失败 | 重试1次；再失败报告艺术总监 |
| 色板冲突 | 调整场景配色避开角色主色 |
| 艺术总监退回2-3次 | 停下，请艺术总监给明确修改方向或请老板介入 |
| 预算耗尽 | 自动停止，通知制片人和艺术总监 |

## 人工兜底
- 场景描述模糊 → 编剧补充明确
- 退回2-3次仍不通过 → 艺术总监给明确方向或老板介入
- 色板冲突无法自动解决 → 角色设计师和艺术总监协调
- 预算熔断 → 老板决定是否追加预算
- 敏感/不可实现场景 → 艺术总监确认替代方案
- 主要检查环节：**艺术总监审核环节**
