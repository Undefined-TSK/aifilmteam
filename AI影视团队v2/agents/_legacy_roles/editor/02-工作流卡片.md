# 剪辑师 工作流卡片

> 版本 v1.0 | 2026-09-25 | 输入：镜头清单+音轨清单 → 输出：成片MP4

## 人工流程（10步）

| 步 | 动作 | 判断点 |
|----|------|--------|
| 1 | 收动画师handoff | 18镜清单？每镜文件存在？ |
| 2 | 收音效师handoff | 四轨素材齐？音轨清单时码对？ |
| 3 | 素材check | 缺件→分镜图顶替/静音标记，不阻塞 |
| 4 | 时间线组装（镜序+时长） | 镜序=分镜表？转场=硬切+场间黑场？ |
| 5 | 降级镜Ken Burns | zoompan参数按运镜指令（push-in/pan） |
| 6 | 四轨混音 | 分层音量+淡入淡出按清单 |
| 7 | 对白字幕 | 镜号对齐，白字黑边 |
| 8 | 调色 | 冷调统一+暖光锚点保留 |
| 9 | 全片自检播放 | 声画同步？时长80s？黑帧？爆音？ |
| 10 | 输出+剪辑记录+handoff终审 | MP4+决策记录齐 |

## 转场规范

| 场景边界 | 转场 | 理由 |
|---------|------|------|
| 同场镜间 | 硬切 | 分镜师节奏设计，不加糖 |
| 1场→2场 | 黑场0.3s+雨声先行 | 情绪跳变（家→街） |
| 2场→3场 | 直接切 | 焦虑延续，不打断 |
| 3场→4场 | 黑场0.3s+BGM主题延续 | 情绪转折呼吸 |
| 4场结尾 | 渐黑2s+雨声淡出 | 收尾余韵 |

## Ken Burns参数基准（zoompan）

| 运镜指令 | zoompan参数 | 适用 |
|---------|------------|------|
| dolly in | z='min(zoom+0.0015,1.15)' | 情绪强调镜（3-3） |
| dolly out | z='max(1.15-0.0015*on,1.0)' | 收尾镜（4-3） |
| pan左→右 | x='iw/2+(on-iw/2)*0.01' | 环境交代 |
| static | 微zoom 1.0→1.03 | 普通静帧防呆板 |

## 混音层次（对齐音效师清单）

| 轨 | 音量基准 | 说明 |
|----|---------|------|
| 对白 | 0dB | 主导 |
| 动效 | -6dB | 突出 |
| 环境 | -18dB | 打底 |
| BGM | -12dB | 衬底（对白段ducking到-18dB） |

## Agent工作流（MUST/SHOULD）

### MUST
1. 镜序严格按分镜表（禁自作主张调序）
2. 降级/顶替镜显式记录（剪辑决策记录）
3. 输出前全片自检播放（时长/同步/黑帧/爆音四查）
4. 成片+剪辑记录+handoff三件齐才算交付

### SHOULD
1. 粗剪先行：素材未齐时先出静帧版粗剪验证节奏（降级不阻塞的逆向应用）
2. 渲染参数：1080p/30fps/H.264高画质，草稿版720p快速迭代
3. session_search查历史剪辑参数复用
