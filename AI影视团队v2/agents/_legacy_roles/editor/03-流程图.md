# 剪辑师 流程图（Mermaid）

> 版本 v1.0 | 2026-09-25

```mermaid
flowchart TD
    A[收动画师handoff<br/>镜头清单+片段] --> B[收音效师handoff<br/>音轨清单+四轨]
    A --> B
    B --> C{素材check<br/>18镜+四轨}
    C -- 缺件 --> D[降级顶替<br/>分镜图/静音标记<br/>不阻塞]
    C -- 齐 --> E[时间线组装<br/>镜序=分镜表]
    D --> E
    E --> F[降级镜Ken Burns<br/>zoompan按运镜]
    F --> G[四轨混音<br/>分层音量+fade]
    G --> H[对白字幕<br/>镜号对齐]
    H --> I[调色<br/>冷调统一+暖锚点]
    I --> J{全片自检四查<br/>时长/同步/黑帧/爆音}
    J -- 不过 --> K[定点修复]
    K --> J
    J -- 过 --> L[输出成片MP4<br/>+剪辑决策记录]
    L --> M[handoff交艺术总监终审]
    M --> N{终审}
    N -- 退回 --> O[按退件三要素修改<br/>哪一段/什么问题/改什么]
    O --> L
    N -- 通过 --> P[老板验收<br/>预览即审批]
    P --> Q[完成]
```

## 关键节点说明

| 节点 | 规则 |
|------|------|
| 素材门 | 缺件降级顶替不阻塞，但显式记录 |
| 镜序门 | 严格按分镜表，剪辑不越权改节奏 |
| 自检门 | 四查（时长/同步/黑帧/爆音）过才输出 |
| 交付门 | 成片+记录+handoff三件齐 |
| 终审门 | 艺术总监退件必须带三要素 |
