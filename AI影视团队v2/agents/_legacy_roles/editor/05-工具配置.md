## 三、合成管线（三阶段）

### 阶段1：单镜预处理（每镜独立处理）
```powershell
# 动态镜：统一转1080p/30fps/H.264（素材规格归一）
ffmpeg -i shots/3-3.mp4 -vf "scale=1920:1080:force_original_aspect_ratio=decrease,pad=1920:1080:-1:-1" -r 30 -c:v libx264 -crf 18 clips/3-3.mp4

# 静帧降级镜：Ken Burns（dolly in示例，3s=90帧@30fps）
ffmpeg -loop 1 -t 3 -i 分镜3-3.png -vf "scale=2880:-1,zoompan=z='min(zoom+0.0015,1.15)':d=90:x='iw/2-(iw/zoom)/2':y='ih/2-(ih/zoom)/2':s=1920x1080:fps=30" -c:v libx264 -crf 18 clips/3-3.mp4
```

### 阶段2：时间线拼接+转场
```powershell
# concat清单（file 'clips/1-1.mp4' ... 逐行）→ 拼接
ffmpeg -f concat -safe 0 -i concat.txt -c copy timeline.mp4
# 场间黑场：单独生成黑场片段插入，或用xfade滤镜
```

### 阶段3：混音+字幕+调色
```powershell
# 四轨混音（分层音量+全局输出）
ffmpeg -i timeline.mp4 -i ambient.mp3 -i sfx.mp3 -i dialogue.mp3 -i bgm.mp3 ^
  -filter_complex "[1:a]volume=-18dB[a1];[2:a]volume=-6dB[a2];[3:a]volume=0dB[a3];[4:a]volume=-12dB[a4];[a1][a2][a3][a4]amix=inputs=4:duration=first[aout]" ^
  -map 0:v -map "[aout]" mixed.mp4

# 调色（冷调统一：微降饱和+压暗+微冷色温）
ffmpeg -i mixed.mp4 -vf "eq=saturation=0.85:brightness=-0.03:contrast=1.05,colorbalance=bs=0.05:ms=0.03" colored.mp4

# 字幕（SRT烧录，白字黑边）
ffmpeg -i colored.mp4 -vf "subtitles=雨夜寻猫.srt:Force_style='FontName=Microsoft YaHei,FontSize=16,PrimaryColour=&HFFFFFF&,OutlineColour=&H000000&,Outline=1'" final.mp4
```

## 四、SRT字幕格式（对白8句）

```
1
00:00:03,000 --> 00:00:05,000
……小白？

2
00:00:07,000 --> 00:00:10,000
窗没关……它肯定出去了。
...
```

> 时码按分镜表镜号起始时间累计（1-1从0s起，镜序衔接）。

| 成片 | 1920x1080 | 30 | 18 | 终审/交付 |
