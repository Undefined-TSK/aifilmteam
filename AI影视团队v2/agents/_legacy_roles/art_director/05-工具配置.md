# 关卡 5：工具配置 — 艺术总监Agent

## 一、概述

本文件记录艺术总监Agent所需全部工具的配置与集成。艺术总监是审核岗——定义风格、把质量门、升级分歧，不生成图像、不消耗预算。需要导演意图维护、交接审核、已锁资产读取和信息检索工具。

**配置原则：** 工具轻量化、结论记录化、复用优先。艺术总监全部复用已有工具（director_intent、handoff_manager、web_search、session_search、K13/scene_lock/charlock读取），无新增脚本。核心是审核结论落盘规范。

## 三、工具详情

### 3.1 导演意图维护（复用）

**脚本路径：** `D:\ai_film_projects\tools\director_intent.py`
**API端点：** `GET /api/intent`

| 命令 | 用途 |
|------|------|
| `read {项目路径}` | 读取导演意图文档 |
| `check {项目路径} {文本}` | 检查文本与文档是否冲突（审梗概/剧本用） |
| `update {项目路径} {字段} {值}` | 更新字段（**当前仅更新时间戳+校验字段名**） |

**check实测局限（2026-09-25）：** 检测逻辑是**完整禁项短语的子串匹配**（禁项 in 文本）——文本"卡通夸张变形风格"能命中（conflict_count=1），但"白天阳光"匹配不到禁项"白天/晴朗场景"（禁项比文本长、语义同义均不可检）。定位=粗筛工具，语义级比对必须靠艺术总监LLM本体逐项核对，MUST NOT 只依赖check结果放行。

**update支持的字段名：** `overall_direction` / `visual_style` / `color_tone` / `mood_atmosphere` / `must_have_elements` / `must_not_have_elements` / `character_notes` / `scene_notes` / `other_notes`

**已知局限（2026-09-25实测）：** update命令的field_map已定义字段映射，但内容替换逻辑未实现完——执行后只更新时间戳并返回updated状态，正文不变。MVP期实际编辑用file工具直接改`director_intent.md`（本项目禁止改官方源码，工具补丁走外部补丁流程，暂不修）。

**规则：** 导演意图文档空缺时编剧不得动笔，MUST 由艺术总监填充或老板定方向。

### 3.2 交接审核（复用）

**脚本路径：** `D:\ai_film_projects\tools\handoff_manager.py`
**API端点：** FastAPI已有封装

**艺术总监使用的命令：**

| 命令 | 用途 |
|------|------|
| `check {项目路径} {handoff_id} {agent}` | 检查交付物质量（issues列表） |
| `accept {项目路径} {handoff_id} {agent}` | 审核通过，下游开工 |
| `reject {项目路径} {handoff_id} {agent} {原因}` | 退回（原因=三要素：哪一件+什么问题+修改方向） |

**审核结论规范：**
- accept = 通过，进入下一环节（落盘/锁定/分发）
- reject = 退回，原因必须可执行（"感觉不对"为非法退回理由）
- 退回达2次 → 不再reject，升级老板

**实战记录：** 2026-09-25剧本v1落盘时创建的handoff（角色设计-20260925-54FE、场景设计-20260925-E49F）当前pending_check，待艺术总监check后accept。
