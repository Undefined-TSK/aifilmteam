### 3.3 K13版本树工具

**脚本路径：** `D:\ai_film_projects\tools\k13_version_tree.py`
**数据格式：** JSON索引 + 文件副本
**存储位置：** `项目路径/k13_locked/`

**核心设计：**
- 锁定版本 = 冻结，不可修改，只能新建分支
- 每个版本有唯一UUID（8位短码）
- 记录完整参数快照，可追溯
- 文件物理复制到k13目录，与生成目录隔离

**功能列表：**

| 命令 | 功能 | 输出 |
|------|------|------|
| `list` | 列出所有锁定版本 | 版本列表摘要 |
| `lock <类型> <名称> <文件> <参数JSON>` | 锁定一个新版本 | UUID + 文件路径 |
| `get <UUID>` | 获取版本详情 | 完整版本信息 |
| `history <资产名>` | 某资产的版本历史 | 时间倒序的版本列表 |
| `branch <父UUID> <分支名>` | 从版本新建分支 | 新UUID + 分支信息 |

**目录结构：**
```
k13_locked/
├── versions.json          # 版本索引
├── character/
│   └── 主角形象/
│       └── a2448fb1/
│           └── sdxl_00001_.png
├── scene/
├── storyboard/
└── video/
```

### 3.4 预算管理工具

**脚本路径：** `D:\ai_film_projects\tools\budget_manager.py`
**数据格式：** JSON（`budget.json`）
**存储位置：** 项目根目录下

**核心设计：**
- 预算硬上限 + 80%预警 + 耗尽自动熔断
- 每笔支出有记录，可追溯
- 熔断后需老板追加预算才能解冻

**功能列表：**

| 命令 | 功能 | 关键输出字段 |
|------|------|-------------|
| `status` | 查看预算状态 | total / spent / remaining / used_percent / warning / critical / frozen |
| `set <金额>` | 设置总预算 | total_budget |
| `spend <金额> <描述> <资产名>` | 记录支出 | spent_amount / remaining / warning / critical |
| `check <金额>` | 检查是否够花 | can_spend (bool) / warning / frozen |
| `add <金额> <描述>` | 追加预算 | added_amount / new_total |
| `history` | 支出历史 | 交易记录列表 |

**预警与熔断规则：**
- 使用率 ≥ 80% → `warning: true`，提醒老板
- 余额 ≤ 0 → `frozen: true`，自动停止生成
- 追加预算后自动解冻

### 3.5 资产清单与依赖管理

**脚本路径：** `D:\ai_film_projects\tools\asset_manager.py`
**数据格式：** JSON（`assets.json`）
**存储位置：** 项目根目录下

**核心设计：**
- 资产类型：角色(character) → 场景(scene) → 分镜(storyboard) → 动画(video)
- 依赖关系：下游资产依赖上游资产锁定后才能开始
- 状态机：pending → generating → review → locked（失败则failed）

**功能列表：**

| 命令 | 功能 | 用途 |
|------|------|------|
| `list` | 列出所有资产 | 总览 |
| `add <类型> <名称> <依赖JSON>` | 添加资产 | 拆解任务后创建 |
| `update <名称> <字段> <值>` | 更新资产 | 状态变更、记录输出文件 |
| `remove <名称>` | 移除资产 | 清理不需要的 |
| `status` | 整体进度 | 完成度百分比、各状态数量 |
| `next` | 下一个可生成的 | 按依赖顺序推进 |
| `plan <指令文本>` | 从指令拆解计划 | 自动识别需要的资产类型 |

**默认依赖链：**
```
角色图 → 场景图 → 分镜 → 动画
```
