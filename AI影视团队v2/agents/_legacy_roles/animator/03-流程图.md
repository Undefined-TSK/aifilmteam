# 动画师 流程图（Mermaid）

> 版本 v1.0 | 2026-09-25

```mermaid
flowchart TD
    A[收到分镜handoff] --> B{check交付物<br/>分镜表/参考图/prompt}
    B -- 不齐 --> B1[退回分镜师]
    B -- 齐全 --> C[accept开工]
    C --> D[读分镜表复述<br/>18镜80s关键镜确认]
    D --> E{预算check<br/>镜数×单镜成本}
    E -- 不足 --> E1[报制片人<br/>调整额度或降级方案]
    E -- 充足 --> F[逐镜生成循环]

    subgraph LOOP [逐镜循环 ×18]
        F --> G{有参考图?}
        G -- 有 --> H[i2v生成<br/>分镜图首帧锚定+运镜prompt]
        G -- 无 --> I[t2i补分镜图<br/>lock注入prompt]
        I --> H
        H --> J[自检四项]
        J -- 不合格且≤2次 --> K[调参重生成]
        K --> J
        J -- 不合格且>2次 --> L[标记⚠️降级<br/>静帧+Ken Burns]
        J -- 合格 --> M[标记✅动态]
    end

    M --> N[生成镜头清单<br/>JSON+MD时码/状态]
    L --> N
    N --> O{清单与文件<br/>一一对应?}
    O -- 否 --> P[补齐缺失项]
    P --> N
    O -- 是 --> Q[handoff交付剪辑师<br/>shots/+镜头清单+降级说明]
    Q --> R[完成]
```

## 关键节点说明

| 节点 | 规则 |
|------|------|
| check门 | 分镜表JSON/参考图/prompt三要素，缺一退回 |
| 预算门 | 预估总耗>剩余额度→必须报制片人，禁止透支 |
| 重生成上限 | 每镜≤2次，超限走降级不硬磕 |
| 降级透明 | ⚠️降级镜显式标注在镜头清单，剪辑师知情 |
| 交付门 | 清单与文件一一对应才可交付 |
