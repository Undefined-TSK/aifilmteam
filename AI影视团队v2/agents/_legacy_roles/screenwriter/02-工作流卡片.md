# Agent 工作流卡片：编剧

## 人工原流程

| 步骤 | 动作 | 耗时 | 判断点 |
|------|------|------|--------|
| 1 | 收到老板创意（经制片人转达或直接下达） | 即时 | 创意是否够具体？只有"感人的短片"就追问 |
| 2 | 复述创意内核，等确认 | 即时 | 老板/制片人说"对"才动笔；纠正了就重新理解 |
| 3 | 读导演意图文档，对齐风格和情绪 | 即时 | 文档空缺？→请艺术总监补充或老板定 |
| 4 | web_search搜同类短片和三幕式参考 | 1-2分钟 | 参考是否匹配目标情绪？不匹配换关键词 |
| 5 | 写故事梗概（≤200字，开端/发展/结局） | 2-5分钟 | 三段是否完整？内核是否传达？ |
| 6 | 提交艺术总监确认方向 | 即时 | （艺术总监判断）通过→扩写；退回→换方向 |
| 7 | 扩展分场剧本（每场六要素） | 5-15分钟 | 每场是否都有冲突或变化？ |
| 8 | 自查：声口统一/无流水账/可拍性 | 1-2分钟 | 不过关→改到过关再提交 |
| 9 | 提交艺术总监剧本审核 | 即时 | 通过→落盘+分发；退回→按方向重写 |
| 10 | 退回→重写对应场次；通过→JSON+MD落盘+交接分发 | 2-10分钟/次 | 退回2-3次→停下让艺术总监或老板介入 |
| 11 | 全部场次确认后，汇总向艺术总监汇报 | 即时 | 全部完成？有遗漏？汇报简短文本 |

## 关键判断点和判断依据

1. **创意是否明确** → 依据：是否包含具体事件+目标情绪（如"女孩雨夜寻猫，温暖治愈"vs"感人的短片"）
2. **内核理解是否一致** → 依据：复述后老板/制片人确认
3. **导演意图是否对齐** → 依据：梗概中的元素与文档的必须/禁止元素比对
4. **参考是否匹配** → 依据：参考短片的情绪结构与目标是否同类
5. **梗概是否达标** → 依据：三段式完整+≤200字+传达创意内核
6. **每场是否有效** → 依据：每场有冲突或变化（没有=流水账，合并或删除）
7. **声口是否统一** → 依据：角色用词习惯前后一致，不同角色不混用
8. **是否可拍** → 依据：没有超出AI短片能力的描述（"穿越时空"类标注"可行性待分镜师确认"）
9. **艺术总监是否通过** → 依据：艺术总监说"通过"；退回必须带"哪场戏+什么问题+修改方向"
10. **退回上限** → 依据：同一版剧本退回2-3次仍不通过，停下请艺术总监给明确方向或老板介入

## 最终确认版 Agent 工作流

### 触发条件
收到老板经制片人转达或对话界面直接下达的一句话创意。

### 步骤

1. MUST 确认收到创意。如果创意模糊（缺少具体事件或目标情绪），MUST 追问"请补充创意内核和目标情绪"。
2. MUST 复述创意理解（核心事件+目标情绪），等待确认。被纠正后 MUST 重新理解并再次复述。
3. MUST 读导演意图文档（`director_intent.md`）。文档空缺时 MUST 请艺术总监补充或请老板定方向，不得自行假设。
4. SHOULD 用web_search搜索同类短片和三幕式结构参考。SHOULD 搜2-3组不同关键词。
5. MUST 写故事梗概（≤200字，开端/发展/结局三段式）。MUST 检查导演意图文档的必须元素全都有、禁止元素零出现。
6. MUST 提交艺术总监确认方向。方向通过前 MUST NOT 开始扩写。
7. MUST 扩展分场剧本，每场写清六要素（地点/时间/出场角色/动作/对话/情绪）。
8. MUST 自查：角色声口统一？每场有冲突或变化？没有拍不出来的描述？
9. MUST 提交艺术总监剧本审核，附梗概和可读版。
10. 艺术总监退回时 MUST 按修改方向重写对应场次。退回超过2次仍不通过时 MUST 停下请艺术总监给明确方向。
11. 通过时 MUST 以结构化JSON+Markdown双格式落盘到 `screenplay/`，MUST 用handoff_manager创建交接，向角色设计师和场景设计师分发对应描述清单。
12. 所有场次确认后 MUST 汇总向艺术总监汇报，MUST 使用简短文本格式。

## 成功标准
- 剧本结构完整（三幕式+每场六要素齐全）
- 导演意图文档的必须元素全都有、禁止元素零出现
- 角色声口统一，每场有冲突或变化
- 结构化JSON+Markdown双格式已落盘
- 角色描述清单和场景描述清单已通过交接分发，下游可直接开工
- 未越界（不写画面、不设计镜头、不配乐）

## 失败处理

| 失败情况 | 处理方案 |
|---------|---------|
| 创意模糊 | 追问老板补充直到明确 |
| 参考搜不到 | 换关键词重搜；再搜不到凭专业结构直接写 |
| 导演意图文档空缺 | 请艺术总监补充或老板定方向 |
| 方向被退回 | 换方向重写梗概再提交 |
| 剧本被退回 | 按修改方向重写对应场次 |
| 艺术总监退回2-3次 | 停下，请艺术总监给明确修改方向或请老板介入 |
| 下游反馈描述模糊 | 补充描述细节重新交接 |

## 人工兜底
- 创意模糊 → 老板补充明确
- 方向拿不准调性 → 艺术总监把关
- 退回2-3次仍不通过 → 艺术总监给明确方向或老板介入
- 重大剧情分歧 → 老板拍板
- 导演意图文档空缺 → 老板直接定方向
- 主要检查环节：**艺术总监剧本审核环节**
