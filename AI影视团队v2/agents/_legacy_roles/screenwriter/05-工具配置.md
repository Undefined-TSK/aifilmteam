# 关卡 5：工具配置 — 编剧Agent

## 一、概述

本文件记录编剧Agent所需全部工具的配置与集成。编剧负责故事梗概、分场剧本、角色描述和场景描述的产出，是纯文本岗——不生成图像、不消耗预算。需要信息检索、文件读写、意图读取和交接管理工具。

**配置原则：** 工具轻量化、数据文件化、调用命令行化。编剧全部复用已有工具（web_search、file、director_intent、handoff_manager、session_search），无新增脚本。核心是剧本落盘规范。

---

| 序号 | 工具名称 | 脚本/来源 | 核心功能 | 状态 |
|------|---------|----------|---------|------|
| 1 | 网页检索 | web_search | 搜索同类短片、三幕式结构参考 | ✅ 已配置 |

**与设计岗的差异：** 编剧无ComfyUI（不生成图像）、无预算管理（纯文本零成本）、无K13锁定（文本版本走文件名版本v1/v2/v3）。这是刻意的轻量化——文本资产的版本管理用文件名递增足够，不引入K13的UUID体系。

## 三、工具详情

### 3.1 网页检索（参考素材）

**类型：** web_search工具
**用途：** 搜索故事素材、同类短片、三幕式结构参考

**搜索策略：**
| 搜索阶段 | 关键词模式 | 目的 |
|---------|-----------|------|
| 结构 | "{短片类型} 三幕式结构 案例" | 确认结构模板 |
| 同类 | "{同类题材} 短片 剧情" | 参考节奏和情绪曲线 |
| 素材 | "{关键道具/意象} 象征 含义" | 深化意象表达 |
| 拓宽 | "{类似创意} 影片 结局处理" | 避免俗套结局 |

**输出：** 参考要点列表（不落盘，直接用于构思）

---

### 3.2 导演意图读取（复用）

**脚本路径：** `D:\ai_film_projects\tools\director_intent.py`
**API端点：** `GET /api/intent`

| 命令 | 用途 |
|------|------|
| `read {项目路径}` | 读取导演意图文档 |

**编剧关注字段：**
- 整体方向 → 剧本主题对齐
- 情绪氛围 → 全片情绪基调
- 必须有的元素 → 梗概自查清单（必须全出现）
- 绝对不能有的元素 → 梗概自查清单（必须零出现）
- 角色/场景设定 → 描述清单的初始依据

**规则：** 文档空缺时 MUST 请艺术总监补充或老板定方向，MUST NOT 自行假设。

---

### 3.3 剧本落盘规范（file工具）

**存储位置：** `项目路径/screenplay/`

**文件清单：**
```
screenplay/
├── {项目名}_梗概.md           # 故事梗概（≤200字，三段式）
├── {项目名}_剧本_v1.json       # 结构化剧本（下游程序读）
├── {项目名}_剧本_v1.md         # 可读版（人审阅）
├── {项目名}_角色描述.md         # 角色描述清单（交接角色设计师）
└── {项目名}_场景描述.md         # 场景描述清单（交接场景设计师）
```

**剧本JSON结构：**
```json
{
  "title": "雨夜寻猫",
  "version": 1,
  "synopsis": "（≤200字梗概）",
  "acts": [
    {
      "act": 1,
      "scenes": [
        {
          "scene_no": 1,
          "location": "出租屋内",
          "time": "雨夜·晚",
          "characters": ["林小雨", "小白猫"],
          "action": "林小雨发现窗没关，小白猫不见了，抓起外套冲出门",
          "dialogue": [
            {"speaker": "林小雨", "line": "小白？你在哪啊……", "emotion": "焦虑(anxious)"}
          ],
          "emotion": "焦虑·紧迫",
          "duration_sec": 20
        }
      ]
    }
  ],
  "character_briefs": [
    {"name": "林小雨", "age": 18, "personality": "安静内向，对猫有责任感", "identity": "女大学生", "clothing": "米色风衣"}
  ],
  "scene_briefs": [
    {"name": "雨夜巷口", "time": "雨夜", "mood": "湿冷·微光·希望", "props": ["路灯", "水洼", "纸箱"]}
  ]
}
```

**版本规则：** 艺术总监退回重写 → 递增版本号（v1→v2），旧版本保留不删除。定稿版以handoff交接为准。

### 3.4 交接管理（复用）

**脚本路径：** `D:\ai_film_projects\tools\handoff_manager.py`
**API端点：** FastAPI已有封装

**编剧使用的命令：**

| 命令 | 用途 |
|------|------|
| `create {项目路径} screenwriter character_designer {任务名} {背景} {交付物JSON} {下游任务}` | 剧本定稿后向角色设计师交接 |
| `create {项目路径} screenwriter scene_designer ...` | 向场景设计师交接 |

**交接内容：**
- 给角色设计师：角色描述清单（character_briefs）
- 给场景设计师：场景描述清单（scene_briefs）+ 对应场次情绪

**下游闭环：** 下游check→accept开工 / reject退回（带原因）。

---

### 3.5 会话搜索（复用）

**类型：** Hermes内置session_search
**用途：** 写梗概前搜索历史会话，确认创意方向未被推翻过

**规则：** 涉及剧情方向的决策（结局、角色命运），MUST 先session_search查历史裁决再动笔。
