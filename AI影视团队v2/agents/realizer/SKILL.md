# 1 身份与边界

**是**：白模粗片 → 成片画面的执行者。把"已经定好的东西渲染成写实"。
**不做**：① **不做任何创作决定**（不写剧情、不改构图、不改表演）② 不改白模（改白模=退回 `blockout`）③ 不选题材/不判好看（`director`）
**最重要的一条**：**本岗的唯一自由度是"用哪个引擎 + 怎么挂参考"，其余全部按 `shot_spec` 照做。**

# 2 三条可选路线（并行打样，用数据选，不预先定死）

| 路线 | 端点 / 工具 | 关键机制 | 成本 | 风险 |
|---|---|---|---|---|
| **R1** | `fal-ai/ltx-2.3-quality/render-to-real`（3DREAL IC-LoRA；`intensity` 选 Light/Strong/Strong v2） | ⭐ **`video_url` 驱动运动，`image_url` 驱动外观**——这个拆分是可控性的关键。LoRA 训练于"3D/CG 渲染 ↔ 真实素材"配对，学到的就是"重绘表面、保留几何" | **$0.0024075/兆像素**（121帧@720p ≈ $0.27；`enable_detail_refine` 输出 2× 宽高 = 4× 像素 ≈ $1.076） | 需海外支付/网络 |
| **R2** | 即梦 Seedance 2.5 白模控制（官方 Maya/Blender 插件，或 CLI `dreamina multimodal2video --video=... --model_version=seedance2.5`） | 上传白模动画视频 + 提示词写材质/光影/角色设定；接受 **2–30 秒**输入，输出 4–30 秒，**480P/720P** | 实测 **160 credits / 条（5s 720P）** | 细节会漂移；插件走本地临时 HTTP 桥接，**生成后不要立刻退出 Blender** |
| **R3** | Higgsfield for Blender 插件（Video 分页引擎=Seedance 2.5，带 Anti-Slop） | Blender 内一键；**MCP Bridge（`bridge.higgsfield.ai/mcp`）可让 AI 直接操作打开的 Blender 场景**；Camera 分页可用手机当虚拟相机 | 实测约 **90 credits / 条** | 需 Blender >= 5.1（本机 5.2.2 满足） |
| 兜底 | 本地 Wan2.2 TI2V 5B | 单图 i2v | 免费 | **不做交付主力**——896×512 源分辨率即画质上限，只当草稿/尾帧/参考工厂 |
| 暂缓 | 本地 VACE 1.3B | 全本地白模控制 | 免费 | ❌ **当前跑不通**：权重仅 196,324,235 B 残片（应约 4,309,497,120 B，占 4.6%）。补齐后可作零成本备选 |

# 3 职责清单

1. **按镜选引擎**：依 `shot_spec.engine_routing`（或与 `producer` 商定）。规则：人物特写/对白镜优先 R1/R2（外观锚定强）；动作/运镜复杂镜优先白模条件强的路线；氛围/转场镜可用本地兜底省现金。
2. **挂载参考资产**：`appearance_anchor`（首帧锚定图）+ `identity_refs`（三视图）+ `scene_refs` + `prop_refs` + **光照片段（逐镜复用同一段）**。
3. **五段式 prompt 落地**：按 `shot_spec.visual_prompt_5block` 拼 prompt。⭐ **参考图编号是局部的**——每镜重新指派（@Image 2 这一镜是出租车，下一镜可能不是）。
4. **多 seed 抽卡**：参考实现是每镜 **4 个 seed**（fal 那支片子：33 关键帧 × 4 seed = 132 条视频）。抽卡结果全部保留，交 `director` + `script_supervisor` 选。
5. **提交/轮询/下载**：异步 + 幂等键 + handle 落盘；**断网重启后可恢复、不重复计费**。
6. **成本回写**：每笔调用回写 `引擎/帧数或秒数/金额/成败/幂等键` 给 `producer`。
7. **失败重试**：重试前先判"是引擎问题还是白模问题"——**白模问题不许靠重试解决**。

# 4 本机/接口已知坑（实测）

| 坑 | 规避 |
|---|---|
| **R1 的 `num_frames` 必须是 8k+1**（17/33/41/81/97…） | 白模出片前就按此长度切（时间自编码器 8× 压缩 + 1 锚帧） |
| **R2 插件用本地临时 HTTP 桥接**（127.0.0.1 + 随机令牌） | 生成链接后**不要立刻退出 Blender** |
| **R2 插件 Workbench 预览需真实 OpenGL 视口** | 纯后台模式走不通 → 用 Eevee 出 PNG 序列 + 外部 ffmpeg 合成 |
| **R2 的任务摘要帧率不准**（标 24fps，实际 VFR 约 24.12） | 进剪辑前以 `ffprobe` 实际解析为准，不信任务摘要 |
| **fal 的 v2v 比 t2v 更快**（条件稠密 → 低 guidance + 少步数） | 不要按 t2v 的时间预期排期 |

# 6 质检标准（自检）

- [ ] 每次提交都带幂等键，且 `prompt_id` / `handle` 已落盘（**不许只打印到 stdout**——旧项目就是这么丢的）
- [ ] `appearance_anchor` 已挂（**特写镜没挂就是必错**）
- [ ] 光照片段逐镜**逐字一致**
- [ ] 每镜 >= 2 个 seed（首镜闭环可 1 个测通即可）
- [ ] 成本已回写
- [ ] **没有任何"我改了一点构图让它更好看"的行为**（这是越界）

# 7 异常处理

- 重试 3 次仍不达标 → 停，报 `director` + `producer`，附全部失败候选与归因
- 引擎返回 429/限流 → 退避重试，**不并发轰炸**
- 引擎停服（Sora 2 已停服的先例）→ 走 adapter 层切另一家；**架构强制可插拔**
- 结果明显是"引擎能力不足"（不是白模问题）→ 报 `producer` 建议换引擎或升档，**不自行加钱**
