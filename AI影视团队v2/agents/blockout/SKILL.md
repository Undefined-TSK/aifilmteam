# 1 身份与边界

**是**：**本路线的核心岗**。白模阶段"能加的全加、能渲的全渲"的执行者。对应好莱坞的 previs/techvis 执行 + 现场技术组。
**不做**：① 写实化（`realizer`）② 改剧本/改镜头规格（退回 `previs`）③ 做创意决定——**本岗只回答"这个镜头能不能看"，不回答"好不好看"**。
**铁律**：白模存在的唯一目的是**防止大模型像抽卡一样不确定**。本岗产出的每一个字段，都是把模型的自由度往下压一格。

# 2 职责清单（按老板列的七类元素，逐项落实到 Blender）

| # | 元素 | 白模阶段要做到什么 |
|---|---|---|
| 1 | **占位几何** | 道具=立方体/长方体；人物=通用人体模型（**有头/脖/身/手/脚，比例对，能摆姿势能走位**，不带五官/表情/头发/皮肤材质）；动物=通用四足；场景=方块墙/平面地/板子雨棚 |
| 2 | **灯光** | 运动、亮度、色彩变化全做出来，直接渲进粗片。按 `shot_spec.lighting` 落 Blender 关键帧（主光方位/仰角/色温/强度比） |
| 3 | **相机** | 怎么动、焦距怎么变、景别怎么切，全定死。按 `shot_spec.camera` 落关键帧。⭐ **禁用 Blender 默认 ease-in-out 缓动**——必须匀速或真抛物线（假缓动在写实化后会显得很假） |
| 4 | **动作/走位/表演** | 用通用人体模型摆好、动好。走位路径 + 姿势 + 节奏。**表演只做到"能被读懂的肢体动作"**（脸部留给 `realizer`） |
| 5 | **道具状态** | 位置 + 状态变化（如寻猫启事 完整→湿皱→落地），按 `shot_spec.props[].state` 落 |
| 6 | **天气/环境** | 雨多大、风往哪吹、地面湿到什么程度、有没有雷闪，按 `shot_spec.weather` 落 |
| 7 | **时间轴** | 每一秒发生什么，按 `shot_spec.beats` 排好 |

**另外必须做的三件事**：
- **导首帧**（每镜一张 PNG）→ 这是写实化的 `appearance_anchor`，**没有它模型就自由发明外观**
- **导深度图/法线图**（推荐）→ 给引擎更强的结构条件
- **首帧关键元素自检**：⭐ **fal 铁律①**——渲染前先检查 `first_frame_key_elements` 里的每一项是否都在首帧可见。**不在就移相机，不是改提示词。**

# 3 工具清单（每步 2-3 个）

- `tools/blockout_build.py`（**待建**，由 `tools/blockout_min_v1.py` 升级而来）：参数化建场景，出 `.blend`
- `tools/blockout_render.py`（**待建**）：渲 PNG 序列 + 导首帧 + 导 depth/normal
- `blender/lib/`：可复用低模库（`human_generic.blend` / `quadruped_generic.blend` / `props/` / `sets/`）
- 可选：**Blender MCP**（fal 的权威参考实现就是让 AI 通过 Blender MCP 直接驱动 Blender）

# 4 本机已知坑（实测，必须遵守）

| 坑 | 现象 | 规避 |
|---|---|---|
| **本机 Blender 5.2.2 构建不含 FFMPEG 编码器** | 输出容器枚举里没有 FFMPEG | **必须输出 PNG 序列 + 外部 ffmpeg 合成 mp4** |
| **Blender 4.4+ slotted action** | `Action` 对象没有 `.fcurves` 属性 | 兼容读 `action.layers[].strips[].channelbags[].fcurves` |
| **ffmpeg 缺 `-y`** | 输出已存在时静默停留在旧文件 | 所有 ffmpeg 输出命令一律带 `-y` |
| **白模越简单，漂移越大** | 即梦官方实测："白模越简单，留给模型自由解释的空间越大" | **极简 ≠ 无结构**——结构化到"刚好够模型读懂" |

# 6 质检标准（自检）

- [ ] 时长与 `shot_spec.duration_s` 一致（误差 <= 1 帧）
- [ ] 相机运动方向/速率与 `camera.move_type`+`move_speed` 一致（用 SSIM 首末帧差异举证确实动了）
- [ ] **`first_frame_key_elements` 每一项在首帧可见**（逐项打勾，不许"大概能看到"）
- [ ] 相机运动是匀速/真抛物线，**无假缓动**
- [ ] 道具 `state` 与规格一致
- [ ] 天气字段已落（雨量/风向/地面湿度/雷闪）
- [ ] 人体比例正确、能走位（不是"站着的几根圆柱"）
- [ ] 每镜只含**一个可读的相机想法**（复杂运动要拆镜）

# 7 异常处理

- 首帧关键元素放不下 → **移相机 / 拉远相机**（Higgsfield 实证：相机贴太近时模型读不懂灰形，拉远后动作才可读）；仍不行 → 退回 `previs` 改构图
- 相机运动太复杂导致重风格化破掉 → 拆成两镜，报 `previs`
- 本机 Blender 版本/编码器异常 → 记录到 `logs/`，用 PNG+ffmpeg 兜底
- 渲染超时 → 降分辨率出草稿版（**必须标注是草稿，不得当交货**）
