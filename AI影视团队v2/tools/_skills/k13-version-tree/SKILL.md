# K13 版本树 Skill

**Skill 名称：** k13-version-tree
**版本：** v1.0.0
**分类：** AI生成 / 资产管理
**关键词：** 版本控制、AI生成、图像管理、版本锁定、参数快照

---

## 一、Skill 简介

K13版本树是为AI生成场景设计的版本管理工具。

AI生成有个痛点：**同一段prompt，每次出的图都不一样**。好不容易出了一张满意的，下一次可能就找不到了。K13版本树解决的就是这个问题——**让满意的结果永远不会丢**。

它就像Git一样管理AI生成的版本，但比Git简单得多，专门为"抽卡式"生成设计：
- 满意就"锁定"，锁定即冻结，永不被覆盖
- 每个版本有独立UUID，随时可以找回
- 完整参数快照（prompt/seed/模型/配置），可复现
- 支持分支探索，试错不影响原版
- 版本历史可视化，一眼看到所有迭代

## 二、适用场景

| 场景 | 是否适用 | 说明 |
|------|---------|------|
| AI图像生成 | ✅ 非常适用 | 每次生成结果不同，需要保存满意版本 |
| AI视频生成 | ✅ 适用 | 视频迭代成本高，更需要版本管理 |
| 提示词迭代 | ✅ 适用 | 记录每个版本的prompt和参数变化 |
| 多方案对比 | ✅ 适用 | 分支探索，最后选最优方案 |
| 团队协作 | ✅ 适用 | 版本有UUID，沟通时直接说编号 |
| 普通文件版本 | ❌ 不适用 | 用Git更合适 |

## 三、核心概念

### 3.1 版本（Version）

一次生成的结果就是一个版本。每个版本包含：
- **结果文件**（图片/视频等）
- **参数快照**（prompt、seed、模型、steps...）
- **元数据**（创建时间、父版本、备注）
- **UUID**（唯一标识符，短8位）

### 3.2 锁定（Lock）

"锁定"是K13的核心动作。锁定后的版本：
- 文件被复制到 `k13_locked/` 目录，永不被覆盖
- 参数被冻结，写入JSON快照
- 后续版本只能从它分支，不能修改它

### 3.3 版本树（Tree）

版本之间有父子关系，形成树状结构：
```
v1 (锁定)
 ├─ v2 (锁定，在v1基础上调整)
 │   └─ v3 (未锁定，试错中)
 └─ v4 (锁定，另一个方向的探索)
```

## 四、安装与使用

### 4.1 环境要求

- Python 3.8+
- 无第三方依赖（纯标准库）

### 4.2 快速开始

```bash
# 1. 在你的项目目录初始化K13
python scripts/k13.py init <project_path>

# 2. 生成一张图后，保存为新版本
python scripts/k13.py save <project_path> <asset_type> <asset_name> \
  --file generated.png \
  --params '{"prompt": "...", "seed": 12345}' \
  --note "第一次尝试"

# 3. 满意了，锁定这个版本
python scripts/k13.py lock <project_path> <asset_type> <asset_name> <version_uuid>

# 4. 查看所有版本
python scripts/k13.py list <project_path> <asset_type> <asset_name>
```

详细命令说明见 [scripts/README.md](scripts/README.md)

## 六、设计原则

1. **文件化存储**：不依赖数据库，JSON + 文件系统，迁移方便
2. **锁定即冻结**：锁定的版本永不修改，这是K13的核心承诺
3. **短UUID**：8位短UUID，够用又好记，方便沟通
4. **零依赖**：纯Python标准库，在哪都能跑
5. **可追溯**：每个版本都有完整参数快照，理论上可100%复现

## 七、从 Agent 工作流提炼

这个Skill是从 **AI影视制片人Agent** 的工作流中提炼出来的。

在制片Agent中，K13版本树是核心基础设施之一——每个资产（角色/场景/分镜）的生成都离不开版本管理。提炼为独立Skill后：
- 可以被其他Agent复用（插画Agent、游戏美术Agent...）
- 可以独立使用，不需要Agent框架
- 可以集成到任何AI生成工作流中

**提炼方法**：从Agent的工具集合中，找出独立的、有通用价值的能力模块，
封装为标准Skill格式（SKILL.md + 脚本 + 示例 + 文档）。
