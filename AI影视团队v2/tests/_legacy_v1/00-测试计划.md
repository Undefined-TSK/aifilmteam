# 制片人Agent 闭环测试计划

## 测试目标
验证制片人Agent能否稳定完成AI影视资产生成任务，覆盖常规场景、复杂场景和边界场景。

---

## 测试样例1：单角色概念图（常规场景）

**场景描述：** 老板要求生成一个赛博朋克风格的女主角概念图，用于科幻短片项目。

**输入指令：**
> "帮我做一个赛博朋克风格的女主角概念图，角色叫林月，25岁左右，短发，穿霓虹色夹克，背景是雨夜的霓虹都市。风格写实，电影感。"

**预期输出：**
- 创建导演意图文档
- 拆解资产清单（1个角色概念图）
- 生成图像并锁定版本
- 预算消耗记录正确
- 最终汇报清晰

**验收标准：**
- [ ] 意图文档创建成功，包含核心创意描述
- [ ] 资产清单正确，只有1个角色资产
- [ ] 图像生成成功，质量可用
- [ ] 版本锁定成功，有UUID和文件快照
- [ ] 预算记录正确
- [ ] 最终汇报告知完成状态和文件位置

---

## 测试样例2：多资产依赖生成（复杂场景）

**场景描述：** 老板要求生成一个场景的多个资产，角色依赖场景的风格设定。

**输入指令：**
> "我要做一个古风短片的开场镜头，先做两个资产：第一个是男主角概念图，白衣剑客，20岁左右，清冷气质；第二个是竹林场景概念图，晨雾中的竹林，有阳光透过树叶。角色要和场景风格统一。预算给200点。"

**预期输出：**
- 创建导演意图文档（古风、竹林、剑客）
- 拆解资产清单（2个资产，有依赖关系）
- 先生成场景，再生成角色（场景先锁定作为风格参考）
- 两个版本都成功锁定
- 预算消耗在限额内
- 依赖关系正确记录

**验收标准：**
- [ ] 意图文档包含古风+竹林+剑客的核心设定
- [ ] 资产清单有2个资产，标注了依赖关系
- [ ] 场景先生成并锁定
- [ ] 角色后生成，参考场景风格
- [ ] 两个版本都有独立UUID
- [ ] 预算使用不超过200点
- [ ] 最终汇报列出全部资产和位置

---

## 测试样例3：预算边界测试（边界场景）

**场景描述：** 预算设置得很低，测试预算预警和熔断机制。

**输入指令：**
> "帮我生成一张未来城市的概念图，预算只有2点。"

**预期输出：**
- 预算检查发现不足（1次生成成本 > 2点）
- 触发预警或熔断
- Agent告知预算不足，询问是否追加
- 不会强行生成导致超支

**验收标准：**
- [ ] 预算检查在生成前执行
- [ ] 正确识别预算不足以覆盖1次生成
- [ ] 触发预警/熔断机制
- [ ] 主动询问是否追加预算
- [ ] 未发生实际超支

---

## 测试流程

每个样例按以下步骤执行并保存证据：
1. 初始状态截图（项目空目录、预算初始值）
2. 发送指令给Agent
3. Agent执行过程记录（日志、中间输出）
4. 最终结果截图（生成的图片、版本文件、预算记录）
5. 人工验收，记录问题
