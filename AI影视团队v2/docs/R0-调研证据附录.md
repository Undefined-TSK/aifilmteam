## B.1 ⭐ 本路线的权威参考实现（决定性发现）

**fal.ai《From clay 3D render to a real action short: a 3D-to-AI pipeline with total control》**
URL: `https://blog.fal.ai/from-clay-3d-render-to-a-real-action-short-a-3d-to-ai-pipeline-with-total-control/`

这是一支**1930 年代沙漠小镇、卡车飞跃蒸汽货运列车**的动作短片，全套流程公开。原文关键句（逐字）：

> "the idea is to split the job: **A 3D blockout owns the geometry** — cameras, motion, timing, cuts. Grey boxes, real physics, zero detail. (**Blender, driven entirely by the AI through the Blender MCP** — no hand modeling.) **Image models own the look** — a set of validated reference images plus one 'keyframe' per shot. **render-to-real owns the final pixels**."

> "And one honest disclaimer up front: **this is not a one-prompt magic trick.** The pipeline runs on **three prompts — one per phase — with a human validation step between each.** ...Every phase involved iteration; first results were often wrong, and that's part of the method, not a failure of it."

**它总结的白模阶段五条硬规则**（逐字要义）：
1. **每一镜的第一帧必须清晰展示所有关键元素**——视频模型由首帧驱动，如果车在第 2 秒才进场，关键帧里没有车，模型就得在镜中段凭空编一个，会漂移。
2. **每镜只放一个可读的相机想法**——过于复杂或暴力的运动会让重风格化破掉。
3. **具体动作 + 清晰角度**；hero 主体每镜都要可见（跨镜一致性来自模型反复看到同一批元素）。
4. **物理运动**：匀速、真抛物线。**假的缓入缓出弧线在写实化后会显得不对**。
5. 某镜不满足规则，就**改剪辑或直接砍掉**——但在 blocking 阶段想到，比在后期便宜太多。

**成本与规模**：33 个已验证关键帧 × 4 个 seed = **132 条视频，0 失败任务**。
**它自己的诚实结论**：这**不是**"一次提示词就出片"。

**Higgsfield《Passport Rush》混合动画短片（2026-09-26 开源全部 prompt 与资产）**
来源：`https://www.ai-primer.com/creative/stories/higgsfield-blender-animation-pipeline`、`https://metallab.ai/en/2026/9/higgsfield-blender-passport-rush`
- 18 场车戏 3 天完成；流程 = 手绘分镜 → Soul 2.0 角色/道具/场景设计 → **Blender 灰模 previs** → 图像参考供给最终外观 → Seedance 2.5
- 实测教训：① 纯水彩背景"没生命"，改成傍晚黄金时刻光照解决 ② 水彩质感的出租车**动起来像"被拉伸的 PNG"**，后来另建干净 3D 版 ③ 某镜 Blender 相机贴太近、模型读不懂灰形，**把相机拉远**动作才可读
- **最重要的方法**：prompt 写成 5 段式模板 —— 场景上下文与风格 / 活动参考 / 镜头构图 / **锁与约束（LOCKS AND CONSTRAINTS）** / 动画十二原则；**光照片段逐镜复用同一段**（锁死光向与色温）
- 制片人原话："**Every detail we don't write, the model decides for us, and the model guesses terribly.**"（我们没写的每个细节，模型都会替我们决定，而模型猜得很糟。）

## B.6 一条"反面证据"（必须给老板看）

《Same Model, Same Story, One Week Apart. What Made the Second AI Blender Film Watchable.》
URL: `https://hellonunc.com/blog/posts/krpan-blender-second-attempt`

同一作者、同一模型、相隔一周做的两部 Blender 短片。第一版不可看，第二版可看。作者的自我披露（逐字要义）：

- 关键不在于换了更好的模型，而在于把 "make it look good" 换成**可检查的断言（checkable statements）**、让模型用它本来不擅长的**外部资产**（MakeHuman CC0 人体 + OpenGameArt 598 顶点马 + Poly Haven CC0 材质）、**用一整夜渲染预算买迭代**、并在 pilot 前放一双**来自另一家厂商的敌意审查的眼睛**。
- 流程：先出 4 张概念目标图 → 整片低分辨率 blockout → **升空镜头的 5 个原生分辨率 pilot** → 独立 critic（不同厂商的 agent）**对每个 pilot 都返回 REVISE** → 部分意见改变成片（"对称双肘上举像木偶"→改成不对称撤回）、部分被导演逐帧驳回并**同时记录批评与分歧** → 然后两遍 2000 帧全量 + 40 帧相机修正。
- 交付：100 秒、原生 1280×720、**20 帧/秒**（README 里写明"**这是制作预算的削减，不是僵硬姿态的解释或借口**"）。
- 成本：导演会话 2.38 亿 input token / 87.9 万 output token；一次撞到周配额上限。
- **它自己的状态文件原话**："models/materials are below the concept references; facial strain remains restrained."
- **最后一条独立 critic 判定仍为 REVISE，导演照样交付并如实说出来。**
- **它明确声明："It still cannot watch or hear its own film."**（它仍然不能看、不能听自己的片子。）

**为什么必须给老板看**：这段是"预期 vs 现实"最诚实的一手材料。**AI 能做出可看的片子，但过程不是一按即出，且需要一双外部敌意的眼睛。** 这正是我在规划书 §2 里提出的对齐方案的核心依据。
