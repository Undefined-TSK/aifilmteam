## 0. 先回答两个核心问题

### ① 「把一段 3D 白模视频重绘成写实画面」= 结构保持型 Video-to-Video（V2V）重绘

**10 家里真正具备的只有 4.5 家：**

| 排名 | 平台 | 依据 | 等级 |
|---|---|---|---|
| 1 | **Runway Aleph / Aleph 2.0** | 纯 V2V，官方原话 "preserving camera trajectories, physical depth"；靠 **depth estimation + 空间重建**反推场景几何，还能**从单条视频生成新机位**（反打/俯拍/环绕）。Edit Studio 支持 ≤30s 序列 | 二手 |
| 2 | **Kling O3(Omni) / O1 V2V** | 官方 V2V 模式明确 **"Base: 对源片直接剪辑与重绘"**；底层 3D 时空联合注意力；MotionControl 具 3D 感知相机控制 | 二手 |
| 3 | **SkyReels V4/V3** | 商用页有 **Video Restyling**；开源 V3 支持 Video-to-Video | 二手 |
| 4 | **Luma Ray3 / Ray3 Modify** | Ray3 自带视觉推理 + 关键帧 + 相机控制，Modify 支持改原片 | 二手 **待验** |
| 5 | **Higgsfield（半个）** | 本身不是模型，是**编排层**。官方与评测都把 Blender 插件定位成「**灰模 previz → 交给 Seedance 2.5 出片**」 | 二手 |

**其余是文字/图片驱动**：Pika、Vidu、Seedance 2.0 只有「参考图/风格迁移」级 V2V，**不是结构保持重绘**；Hedra 只做口型数字人；oiioii 是动画 Agent 编排层；LTX Studio 主体是分镜编排（有 V2V 模式但非核心卖点）。

### ② ⭐ 护城河落点（本报告最重要的一条）

**这 10 家没有一家把「深度图 / AOV / 几何 / 渲染通道」当一等公民输入**——全部是「**从 RGB 视频反推深度**」。
→ **我们若把 Blender 的 `depth` / `normal` / 相机元数据「显式喂给」写实化模型，是别人没有的接口层。**
（依据：10 家官方文档层面均未见该输入项，属"**未找到**"，非"确定不存在"。）

### ③ ⚠️ 我此前一个判断要修正

**"直接竞品 = oiioii"是错的。** oiioii 卖的是"动画成片 Agent"，**与我们路线正交**。
真正路线同构的是 **Higgsfield（Blender 插件 + MCP Bridge + Cinema Studio 相机控制）**——它已经被市场验证过一遍"灰模变实拍"，**是最该抄作业、也最该防的对象**。

## 1. oiioii.ai —— ⚠️ 条件用（对标但不威胁）

- **定位**：7 个 Agent（编剧/艺术总监/角色设计师/分镜师/场景/音乐/产品）自动出 60s+ 动画成片
- **结构控制**：❌ 无 3D/白模/深度输入；控制手段 = 文字 + 参考图 + 150 风格预设
- **V2V 重绘**：无
- **定价（积分式已折算）**：BASE ¥88≈$12/1620 分；STAR ¥259/3930；PRO ¥639/9240；APEX ¥1319/19550。另一口径 $9/1000、$25/3000、$84/8000、$169/18000 → **两口径冲突**。社区折算 **≈$10/成片分钟**
- **开源**：完全闭源｜**API**：Studio 档（$99）含｜**国内直连**：可（中文站）
- **商用版权**：官网公告 "creators keep full ownership and commercial rights"
- **反方证据**：B站/快搜实测长评——"配音不稳定、同角色声线前后变换""分镜衔接生硬""修改入口混乱，一个分镜改十几轮没改好""等半天出不来""视觉风格不一致，人设图和成片两个人""143 个风格真能稳定出片的没几个"；官方自己也承认"邀请码少是因为产品能力还没达标"
- **决策**：⚠️ 只把它的**多 Agent 编排思路**当产品参考，**不要采购**

## 2. Runway —— ✅ 可用（重点研究对象）

- **定位**：AI 生成 + AI 剪辑 + 表演捕捉的多模型生产工作台
- **结构控制**：⚠️ 有 **Act-Two 表演/姿态捕捉**、**Custom Camera**（焦距/光圈/ISO/快门角数值控制）、Aleph 深度估计；**但无 3D/白模/深度图输入口**
- **V2V 重绘**：✅ **Aleph 2.0 = 行业最强**
- **定价**：Gen-4.5 **12 credits/s**（$0.01/credit → **$0.12/s**）。Standard $12/625 分 ≈52s → **$0.23/s**；Pro $28/2250 ≈187s → $0.149/s；Max $76/9500 ≈791s → $0.096/s。**Aleph 2.0 = 28 credits/s**，最低 56 分/次（**$0.56**）；另一口径 Aleph API 15 credits/s（**冲突**）
- **开源**：闭源｜**API**：✅ 自助 docs.dev.runwayml.com + MCP server
- **商用版权**：一手条款——"所有档位保留上传与生成内容权利，含商用"
- **反方证据**：**2026-06-01 砍掉 Unlimited 档、改 Max，老用户被中途迁移，同期涨价 20–50%**；Trustpilot **1/5（23 条）**；"failed generations 照样扣分不退"；"Runway Agent 一次烧 600 分、生成前不告知"；"不能用免费积分除非先付费"；客服纯机器人无人工通道
- **决策**：✅ **首选对标与验证对象**——Aleph 是唯一被公开验证"保相机轨迹 + 物理深度"的 V2V

## 3. Pika —— ⚠️ 条件用

- **定位**：社交短视频 + 特效套件（Pikaffects/Pikascenes/Pikadditions/Pikaswaps/Pikaframes/Pikaformance）
- **结构控制**：❌ 无 3D/深度；最强是**关键帧插值 Pikaframes（≤25s）**与**音频驱动口型 Pikaformance**
- **V2V 重绘**：⚠️ 只有特效级（往原片插物、变换），**非结构保持写实化**
- **定价**：年付 Basic $8/700 分、Standard $28/2300、Fancy $76/6000。Pikaformance **3 分/s**；Pikaframes 1080p/25s = 200 分
- **反方证据**：**Trustpilot 1.6/5、约 87% 一星**（对比 App Store 4.7/5）；"failed generations 照扣分、额度月中突然清零""billing 投诉多而频繁"；画质明显低于 Runway/Kling
- **决策**：⚠️ 仅作"效果类"备选

## 5. Higgsfield —— ✅ 可用（路线最同构，必抄必防）

- **结构控制**：✅ **10 家最强**——Blender 插件 7 分页，**Scene Builder 产出的是真几何体**；MCP Bridge 让 Agent 直接操作**当前打开的 Blender 场景**；Cinema Studio 提供电影级相机控制
- **V2V 重绘**：✅ 有，**但它自己不产模型，是编排**
- **定价**：Starter $19/年付/270 分、Plus $47、Ultra $99/3000 分 → **$0.033–0.070/分**；另一源（6 月）Plus ~$40、Business $89、Ultra $129 → **口径冲突**
- **商用版权（一手 ToS）**：不主张用户输入/输出所有权、**不限制商用**、权利退订后仍有效；**但标准用户内容可能被用于训练模型**；企业档保密并排除训练；输出"可能非唯一"
- **反方证据**：**"Unlimited"电池节流被判"欺骗性"**（53 赞 Reddit 帖）；Reddit 记录 **3 个月内积分成本涨 2–6 倍**；**$350+ 年付退款陷阱**（客服援引自家 ToS 拒退，仅威胁银行拒付后才退且扣 6% 手续费），**mod 删帖压制投诉**；Trustpilot 3.2；"生成时间从 <1 分钟变最长 5 小时"
- **决策**：✅ **第一优先：抄它的 Blender 插件形态与 MCP 架构，但不依赖它做生产**

## 6. Hedra —— ❌ 排除

- **反方证据**：Trustpilot 约 **2.1/5**（集中在计费与客服）；积分不结转
- **决策**：❌ **与本路线无关**（后期若需配音/口型可单独接 API）
