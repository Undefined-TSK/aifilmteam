## 3. 现实剧组职能体检：不加人的修法

> 方法：把真人剧组的**职能**（不是岗位名）逐条落到本项目现有机制上，判"缺失 / 形同虚设 / 已有但工具不支持 / 已到位"。结论：**19岗位覆盖≠职能覆盖**，真空5项，但**全部可以脚本化或字段化补齐，一律不新增bot**。

| 真实职能 | 真人剧组靠什么达成 | 本项目现状 | 修法（不加岗） |
|---|---|---|---|
| **DIT／数据管理员** | 素材入库、checksum、3-2-1备份、LUT/CDL套用、素材→时间线索源 | **完全缺失**。K13只锁参数不锁图像血缘（见E12，5个0字节png仍在册） | 新建 `tools/dit_ingest.py`：每次生成入册一条血缘记录（引擎+模型版本+seed+prompt哈希+**参考图哈希**+产物sha256+光流分+质检分+花费），入 `projects/<片>/ditmap/`；K13锁定时校验文件sha256，坏条目自动 `invalid:true` |

### 3.2 开拍单字段缺口（可直接抄进模板）

手册3.3的3-3示例只有：叙事／引擎路／H3描述／参考挂载／运镜／质检／预算／验收。**真人剧组的 camera report 有而我们缺的字段**：

```
用途(建立/关系/动作/插入/主观/反应) | 景别(VLS-WS-FS-MS-MCU-CU-ECU-BCU) | 焦段mm | T值 | 机位高cm
水平角/俯仰角 | 焦点目标与落点 | 快门角(24fps→180°) | 运动类型+速率(dolly m/s、pan °/s、手持抖幅%)
主光: K值/方位角/仰角/强度比 | 辅光比 | 逆光/实用光源 | 雾尘量 | 反射面
调色锚 hex | show LUT 版本 | 画内声点(diegetic) | room tone 层 | 视线方向/屏幕方向(跨轴检查用)
白名单道具＋道具状态(满/半/空) | 天气与地面湿润度 | take数与候选池 | 该镜废片判据(见§7)
```

**镜头语法（避免PPT的结构性配平）**：每场景至少"动作镜＋反应镜"成对；三镜覆盖（全/中近/细部）；相邻镜景别跨度≥2档；ASL 控制在 2–5s。现状18镜/80s＝ASL 4.4s 本身合格，**问题全在"无第二运动元素＋无反应镜"**（88.9%是静图，10个静图镜头共用同一套缓推）。

## 7. "实拍感"的可测判据（把主观打回变成数值门）

**先说清因果**：实拍感的底盘=**主体不漂移＋光影连续＋动作真实**；颗粒/LUT/暗角只是皮相，**掩盖级**。所以质检必须分两层。

| 层 | 判据 | 阈值/做法 | 工具 |
|---|---|---|---|
| **技术门（硬，不过不得进预览）** | 无>0.5s黑帧/冻结帧 | `freezedetect=n=-60dB:d=0.5` | ffprobe |
| | 闪白/爆闪 | 每帧亮度差分≤3次/s 越限 | `signalstats`+`metadata=eq` |
| | 帧率与母版一致、无judder | 24fps交付；错帧检测用 `mpdecimate` 统计 | ffprobe |
| | 响度/真峰 | 网络 **-14 LUFS ±0.5 / TP≤-1.5**；广电 -23/-24 LKFS ±2 / ≤-1dBTP（Netflix Atmos口径：对白门控 -27 LKFS） | `ebur128` 两遍 |
| | 分辨率/码率 | 交付档≥手册6.1；AI片段中间码率 crf≤16 | ffprobe |
| | 字幕 | ≤2行、每行≤42字、单条0.5-7s、居中安全区 | 校验脚本 |
| | **运动真实性抽检** | 背景光流中位速 <2px/帧 → 判"静图充数"，**自动打回**（这条直接锁死PPT复发） | cv2 Farneback（本机） |
| **一致性门（半硬）** | 相邻镜人脸相似度 | ArcFace 余弦 ≥0.75（同人），低于即漂移 | 本地模型 |
| | 服装主色 | ΔE ≤ 12（对照服装定妆帧） | LAB 色差 |
| | 光向连续性 | 主光方位角跨镜变化 ≤30°；视线方向按半屏符号判**跨轴报警** | VLM 抽检 |
| | 道具状态 | 建物件状态机（寻猫启事：完整→湿皱→地上），逐镜核对 | 场记清单 |
| | 口型 | Sync-C ≥5（或 VLM 三项：张嘴幅度/闭嘴时段/音节数差≤1） | 抽检 |
| **创意门（软，老板判）** | 表演/情绪/节奏 | 导演Dailies圈take，废片理由必填到帧/秒（红线规则沿用） | 人 |
