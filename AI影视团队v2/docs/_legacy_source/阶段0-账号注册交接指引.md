# 阶段0账号注册交接指引（老板手动步骤）

> 日期：2026-09-26 ｜ 配套：《好莱坞大片级对标与全阶段零返工执行手册.md》3.1节前置条件0.2-0.7
> 双击 `D:\ai_film_projects\start_账号注册向导.bat` 可按顺序打开以下全部页面
> 预计耗时：15-20分钟 ｜ 全程零风险（不生成不扣费）

---

## 一、阿里云账号（Wan 3.0 + 可灵共用，手册拍板项#13）

1. 打开 https://account.aliyun.com/ 注册或登录（已有账号直接登录）
2. 完成实名认证（个人认证即可：支付宝扫码，约2分钟）
3. 进入百炼控制台：https://bailian.console.aliyun.com/
4. **地域选"北京"**（Wan 3.0免费额度30秒限北京地域，90天有效）
5. 开通模型服务（首次进入会提示开通百炼服务，免费开通）
6. 开通两个模型：
   - **Wan 3.0**：模型广场搜"wan"→ wan3.0-video → 立即开通（无需申请）
   - **可灵3.0**：模型广场搜"kling"→ 立即开通（与Wan 3.0同Key同地域）
7. 创建API Key：控制台右上角头像 → API-KEY → 创建 → 复制保存
8. **充值**：百炼控制台 → 费用中心 → 充值 **30元**
9. **开启"免费额度用完即停"**：费用中心 → 资源消费设置（防超扣）

## 二、MiniMax账号（H3引擎）

1. 打开 https://platform.minimaxi.com/ 注册（手机号即可）
2. 完成实名（国内主体流程）
3. 创建API Key：控制台 → API Keys → 创建 → 复制保存
4. **充值**：充值中心 → **20元**
5. 新账号免费1积分（价值微小，忽略）

## 三、交给助手的两个Key

| Key名 | 来源 | 用途 |
|---|---|---|
| DASHSCOPE_API_KEY | 百炼控制台 | Wan 3.0 + 可灵3.0（同Key） |
| MINIMAX_API_KEY | MiniMax控制台 | H3引擎 |

**发Key时建议**：直接粘贴给助手即可，助手自动完成剩余步骤（写入项目.env + 各发1次最小调用验证计费逻辑——手册前置条件0.6/0.16）。

---

## 安全说明

- 两个Key只写入本地 `D:\ai_film_projects\.env`（不入git，项目.gitignore已配）
- Key泄露可随时在控制台吊销重发
- 阶段0预算上限50元封顶已拍板，"用完即停"开启后不会超扣

## 老板操作完成后的自动步骤（助手执行）

1. Key写入 `.env`（DASHSCOPE_API_KEY / MINIMAX_API_KEY）
2. 各发1次最小调用验证（480P最短时长，失败核实不计费规则）
3. 免费额度确认（Wan 3.0共30秒）
4. 账本初始化（budget_manager 记录充值余额）
