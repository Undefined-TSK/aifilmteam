# AI影视制片人 Agent 使用说明书

## 一、Agent 简介

**名称：** AI影视制片人（Producer Agent）
**版本：** v1.1
**类型：** 创意生产 / AI影视资产生成

这是一个帮你管理AI影视资产生成全流程的数字员工。你只需要告诉它你想要什么，它会自动拆解任务、调用AI生成工具、管理版本、追踪预算，最终交付满意的成果。

就像一个真正的制片人——你告诉它"我要一个赛博朋克风格的女主角"，它会帮你把想法变成一张精美的概念图，中间的所有技术细节它都帮你搞定。

## 三、怎么用（3步上手）

### 第1步：发指令

直接用自然语言告诉它你想要什么，越详细越好。

**好的指令示例：**
> "帮我做一个赛博朋克风格的女主角概念图，角色叫林月，25岁左右，短发，穿霓虹色夹克，背景是雨夜的霓虹都市。风格写实，电影感。预算100点。"

**模糊的指令示例（会被追问）：**
> "帮我做张好看的图"
> （Agent会反问："什么风格？什么内容？请补充一下方向"）

**指令建议包含：**
- 🎨 风格（写实/卡通/古风/赛博朋克...）
- 👤 主体（角色/场景/物品...）
- 📝 细节描述（服装、表情、环境...）
- 💰 预算（给多少预算点数）

### 第2步：看预览，给反馈

Agent生成图像后，会把预览图发给你看。这时候你可以：

| 你的反馈 | Agent会做什么 |
|---------|--------------|
| "可以，锁定" | 把这个版本冻结保存到版本树，以后随时可以找回 |
| "不满意，重做" | 调整参数重新生成 |
| "把头发改成长发" | 按你的修改意见调整prompt，重新生成 |
| "换个角度" | 修改构图参数，重新生成 |

**小提示：** 不满意的话最多可以免费重试2次，2次后Agent会停下来让你介入，避免浪费预算。

### 第3步：拿到成果

所有资产都满意并锁定后，Agent会给你一份汇总：
- 每个资产的最终版本
- 文件存放位置
- 预算使用情况
- 整体进度

你可以在项目目录里找到所有锁定版本的原始文件，随时可以取用。

## 四、核心功能详解

### 4.1 导演意图文档

每个项目有一份"导演意图文档"，记录项目的整体风格、关键元素、禁忌事项。这是所有生成的基准，确保多次生成的结果风格统一。

- 新项目会自动创建意图文档
- 新指令和已有文档冲突时，Agent会停下来问你"以哪个为准"
- 你可以随时要求Agent修改意图文档

### 4.2 K13 版本树（版本锁定功能）

AI生成像抽卡，每次结果可能不一样。K13版本树就是解决这个问题的：

- **锁定 = 冻结**：你说"锁定"，那个版本就变成不可修改的了
- **每个版本有独立UUID**：不会被新生成的覆盖
- **参数快照**：每个版本都记录了当时用的prompt、种子、参数，随时可以复现
- **版本历史**：可以查看某个资产的所有历史版本
- **分支功能**：想试另一个方向？从满意的版本分出一个分支，不影响原版

> 类比：就像游戏存档，满意了就存个档，以后想回来随时可以读档。

### 4.3 预算管理

AI生成是有成本的（电费、模型费用等），预算管理功能帮你控制开销：

- **设置总预算**：项目开始时设定一个上限
- **生成前检查**：每次生成前先检查够不够钱
- **80%预警**：用了80%时提醒你"快没预算了"
- **自动熔断**：预算用完自动停止，不会超支
- **追加预算**：钱不够了可以随时追加，追加后自动解冻

### 4.4 资产依赖管理

复杂项目有多个资产，它们之间有依赖关系（比如角色要和场景风格统一）：

- **默认顺序**：角色 → 场景 → 分镜 → 动画
- **按顺序生成**：前面的资产锁定后，后面的才能开始
- **进度追踪**：实时显示哪些完成了、哪些待办
- **下一个可生成**：自动告诉你下一步该做哪个

## 五、项目文件结构

每个项目是一个独立的文件夹，结构如下：

```
你的项目名/
├── director_intent.md    # 导演意图文档（风格基准）
├── assets.json            # 资产清单（所有资产和状态）
├── budget.json            # 预算数据（收支记录）
├── k13_locked/            # K13锁定版本库
│   ├── versions.json      # 版本索引
│   ├── character/         # 角色类资产
│   │   └── 角色名/
│   │       └── UUID/
│   │           └── 图片文件
│   └── scene/             # 场景类资产
│       └── 场景名/
│           └── UUID/
│               └── 图片文件
└── 生成的预览图.png       # 未锁定的临时预览文件
```

## 六、常见问题

**Q: 生成的图不满意怎么办？**
A: 直接告诉Agent哪里不满意，它会调整参数重新生成。建议每次只改一个点，这样更容易判断哪个调整起了作用。

**Q: 可以生成多少张图？**
A: 取决于你的预算。SDXL图像约10点/张（实际成本因硬件而异），预算用完会自动停下。

**Q: 满意的结果会被覆盖吗？**
A: 不会。只要你说"锁定"，那个版本就会被冻结保存到K13版本树里，有独立的UUID，永远不会被覆盖。

**Q: 可以同时生成多个角色吗？**
A: 可以。你可以在指令里说清楚有几个角色、分别叫什么、各自什么特点。Agent会拆解成多个资产按顺序生成。

**Q: 生成需要多长时间？**
A: SDXL 1024x1024图像，在RTX 5070上约12-16秒/张。具体时间取决于图像尺寸、步数和硬件配置。
