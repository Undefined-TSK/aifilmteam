## D. ViMax源码级可抄要点（第二批调研成果，阶段2质检流水线蓝本）

> 来源：github.com/HKUDS/ViMax（MIT协议）源码直读 + deepwiki解读

### D.1 自动一致性检查的真实实现（比传闻更朴素，但可扩展）

核心文件 `agents/best_image_selector.py`（`BestImageSelector`类）：

1. **机制**：多候选图并行生成 → VLM将候选图+参考图+目标描述一起评估 → 输出`best_image_index`+`reason`（Pydantic结构化输出）
2. **检查三维度**（官方prompt模板）：
   - 角色一致性：性别/族裔/年龄/面部特征/体型/发型
   - 空间一致性：角色相对位置/场景布局/透视
   - 描述准确性：是否忠实目标文本（忽略编辑类指令）
   - 附加规则：优先无白边/黑边图；多图均不达标时选相对最优并说明不足
3. **容错**：`@retry`最多3次；返回索引无效时回退候选0
4. **真相**：源码并无"分数阈值不过审强制重生成"逻辑——**我们要做的增强**：把"选最优"升级为"达标注记+不达标触发定向重生成"（这正是场记岗比ViMax更进一步的地方）

### D.2 智能参考图选择（`agents/reference_image_selector.py`）

- 按目标帧描述+镜头角度（camera_angle/shot_type匹配portrait view）从历史帧序列选参考图，含fallback链
- 三类一致性约束：角色（外貌/服装/表情/姿态）、环境（背景/光照/氛围/布局）、风格（写实/电影感/色调）

### D.3 Agent间数据流与配置（对齐我们的handoff）

- 数据流：Pydantic模型（`BestImageResponse{best_image_index,reason}`、`ExtractCharactersResponse{characters[]}`）+ prompt文本 + 图片base64
- 配置（`configs/idea2video.yaml`）：chat_model/image_generator/video_generator三段YAML分离，`class_path+init_args`可替换后端（README已列MiniMax provider/Seedance支持）+ 每服务独立rate limit配置
- **抄法**：我们的引擎接入层直接照此设计——YAML声明式多引擎注册+限流防御

## F. 云端引擎Prompt工程手册（官方文档直取）

### F.1 H3官方提示词手册（github.com/MiniMax-AI/MiniMax-H3 → skills/h3-prompt-writing/SKILL.md）——**编剧/摄影指导/声音设计师联合产出的镜头描述直接用这个结构**

```text
integrated_multimodal_description:
[Shot 1] style + composition + subject + action
[Shot 2] At 00:05.000, cut + camera + result

overall_soundscape:
ambience + physical sounds + non-verbal sounds

non_diegetic_music:
instruments + tempo + dynamics, or N/A
```

- 切镜用递增时间戳（At 00:05.000）
- 运镜术语：Push In / Pull Out / Pan / Truck / Tilt / Arc / Tracking / Static / POV
- 声音三分类：对白入时间线、环境+动作声入soundscape、观众侧配乐入music
- 五模式各有写法：T2VA（从零构建）/ I2VA（锚定首帧描述发展）/ FL2VA（描述首尾帧间路径）/ L2VA（从末帧反推）/ Ref2VA（先定义`<Picture 1>`/`<Video 1>`/`<Audio 1>`标签，再声明保留/迁移/编辑关系）

### F.2 Wan 3.0 API参数速查（阿里云官方）

- **无独立camera参数**——运镜全靠prompt多镜头写法（Shot 1/Shot 2描述式）
- 指令编辑：`input.media[]`传`reference_video`（type字段）+prompt指令
- 参考引用写法是**"Image 1"（带空格）**，非"@Image1"；图片视频分开计数（Image 1与Video 1可共存）
- 参数枚举：resolution=480P/720P/1080P（默认1080P）、ratio=adaptive/21:9/16:9/4:3/1:1/3:4/9:16（默认adaptive）、duration=[2,30]或-1智能、audio=true/false、prompt_extend、watermark
- 异步：`X-DashScope-Async: enable`头→task_id→轮询

### F.3 Wan 2.2美学控制=纯prompt工程（无DSL）

官方文档确认"支持光影/色彩/构图多维控制"但无节点级语法，靠自然语言+影视术语：

| 类别 | 术语库（影视通用英文术语） |
|---|---|
| 光照方向 | rim lighting / side light / back light / top light |
| 光照氛围 | soft lighting / hard lighting / low key / volumetric fog / god rays |
| 色温 | golden hour / blue hour / warm tones / cool tones / desaturated |
| 景别 | extreme long shot / wide / medium / close-up / low angle / high angle / over-the-shoulder |
| 运镜 | push in / pull out / pan / tilt / tracking shot / arc / dolly / static camera |

模板样例：`[主体+场景+运动] + [景别+角度] + [光影术语] + [色调] + [运镜描述]`——灯光师prompt库直接以此建库。
