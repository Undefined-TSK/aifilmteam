## 4. 资产迁移原则（报老板拍板后执行）

1. **只复制，不移动**（旧目录保持原样可回滚）；除非老板明确要求移动。
2. **按"资产类型"重组为新结构**，不照搬旧目录树（旧树有大量历史层级）。
3. **每类资产带一份 `_manifest.json`**：来源路径 + 原 sha256（迁移后校验）+ 原始生成参数 + 归属项目 + 可用性判定。
4. **落地前逐项核对**：本表登记的数量/体积必须与迁移后完全一致，不符即报错停止。
5. **0 字节与测试夹具资产标记 `invalid`/`fixture` 后仍迁入**（不删，但代码不得引用）。
