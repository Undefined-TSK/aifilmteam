## 对照 C：量级差 vs 审美差

**结论（先给答案）：差的主要是「量级差」，审美差是从属结果，不是并列的第二主因。**

依据：审计件 §4.2 原文——「**代差是量级差、不是审美差**：本地 3-3 镜源分辨率 896×512，而云引擎原生 1080P 起」。本 AI 复核 concur。

### C.1 量级差（可量化，逐项列数）

| 维度 | 现状（实测） | 目标基线 | 倍数/差值 |
|---|---|---|---|
| 视频分辨率 | 896×512 / 832×480（2 条真动镜源） | 1920×1080 | 线性 **2.14× / 2.31×**；面积 **4.6× / 5.1×** |
| 交付分辨率 | 1280×720 | 1920×1080 | 面积 **2.25×** |
| 码率 | 1.567 Mbps | ≥ 8 Mbps（本地审片档下限） | **5.1×** |
| 音频采样率 | 44100 Hz | 48000 Hz | 偏低一档（工业制作标准） |
| 集成响度 | -20.83 LUFS | -14 LUFS ±0.5 | **差 6.8 LU** |
| 真动态镜占比 | 2/18 = **11.1%** | 阶段 0.5 目标 ≥ 70% | **6.3×** |
| 云端引擎接入 | 0 个 | 3 个（wan2.6 / H3 / 可灵） | **0 → 3** |
| 帧率一致性 | 24fps 源塞 30fps 时间线 | 全片 24fps CFR | 存在 judder |
| 未提交变更 | 196 项 / 2 commits | 每阶段一次 commit | 无回滚点 |
| 19 轨签核 | 0 / 19 | 19 / 19 或全部 signoff | **全部未签** |

**量级差的本质一句话**：这台 12GB 机器出的东西**不在 2026 年的工业基线上**——分辨率差 2 倍多、码率差 5 倍、响度差 6.8 LU、真动比例差 6.3 倍。这不是"再调调参数"能补的，是**换引擎才能补的**。

### C.2 审美差（次要，且部分由量级差导致）

| 审美维度 | 现状 | 说明 |
|---|---|---|
| 镜头语法配平 | 10 个静图镜共用同一套缓推；18 镜无"动作镜+反应镜"成对 | 属**真审美差**（§3.2） |
| 表演层次 | 无"情绪标签＋强度 1-5＋视线方向＋动作节拍"字段，Dailies 审的是静帧 | 属真审美差 |
| 第二运动元素 | 静图镜无任何画面内独立运动 | **由量级差导致**（静图根本没有运动可言） |
| 光影连续 | 10 个静图共用一套 LUT/缓推，无光向连续性判据 | 属真审美差（缺判据，非缺能力） |
| 声音设计 | 69 秒单层硬雨、无 room tone 分轨、对白为朗读式 | 属真审美差（缺决策者与判据，§6.2） |

**为什么不许说"都有"**：因为两者是**因果关系而非并列关系**——分辨率/码率/动态比例不到量级，任何审美设计都无从落地（静图没有运镜、没有表演、没有第二运动元素）。正确表述是：

> **先补量级（换云引擎 + 全镜头动态化 + 交付规格归一），再审美（镜头语法配平 + 表演字段 + 声音分轨）。量级不补，审美工作是空转。**

### C.3 但必须同时承认"审美差不是量级差的影子"

有 4 项差距**换了引擎也不会自动消失**，必须单独做：
1. 镜头语法配平（动作/反应镜成对、相邻镜景别跨度≥2 档）——**结构性配平问题**。
2. 表演字段（情绪/强度/视线/节拍）——**字段化问题**。
3. 光向连续性判据（主光方位角跨镜 ≤30°、跨轴报警）——**判据问题**。
4. 声音决策（-27~-24 LUFS 对白锚点、per-shot 混响、room tone）——**判据+分轨问题**。

→ 所以最终结论：**量级差是主因（约占 7 成），审美差占 3 成，且这 3 成必须独立补，不能指望换引擎自动解决。**
