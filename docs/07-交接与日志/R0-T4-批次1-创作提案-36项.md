## 〇、提案级约定（需 owner 确认，非既有规范）

1. **pos/aim 坐标系**（timeline 19 轨与 schema 均未定义格式，此处提案）：单位米，场景局部坐标系——x=画面右，y=纵深（远离初始机位方向），z=自地面向上；aim=注视点坐标 [x,y,z]。02_blockout 目前为空，所有数值为"待 blockout 建场后量取校准"的提案值。
2. **key_dir_az_deg 方位约定**：az 0°=画面纵深方向（y+），90°=画面右（x+），270°=画面左，逆时针为负。schema 仅约束为 number，无域定义，故按提案约定填值。
3. **fill_ratio 语义**（按 2026-10-03 复核后的 schema 最新口径）：schema 已改为 `exclusiveMinimum 0 / exclusiveMaximum 1` 的小数域——"光比填充率，如 1:4 → 0.25"（R0-T3b 统一口径，废弃旧"1:3 → 3"分母整数口径）。本文件 fill_ratio 全部为小数：数值越小辅光越弱、反差越高。
4. **key_intensity**：相对值，基准 1.0 = 该场景标准主光曝光。schema 无域限制，提案值控制在 0.6~1.3。
5. 色温/方位角均在 schema 合法域（number）内；camera 的 move_type/focal_mm/t_stop 已有定值，不在本提案范围。
