## 一、改造背景

根据《03-one-size-fits-all-audit.md》一刀切审计报告，以下五项决策点存在"一刀切"问题：
- **D15**：OKLCH色板规模固定为48色，无法适应不同复杂度场景
- **D16**：单镜对象上限固定为≤8，无法适应简单/复杂镜头差异
- **D22**：渲染健康线固定为3s/帧，无法适应不同分辨率档位
- **N13**：撤销步数固定为50步，无法适应不同操作习惯
- **N21**：图规模上限固定为≤60节点，无法适应不同项目规模

---

## 二、改造详情

### 2.1 D15 - OKLCH色板规模（扩展为三档）
**原决策**：48色（暖16+冷16+中性16）固定
**新决策**：**三档可配**
- **轻量档**：24色（单角色简单场景）
- **标准档**：48色（标准项目）
- **重量档**：96色（群戏+复杂场景）
**应用场景**：单角色访谈类项目 / 标准剧集 / 群戏复杂场景

### 2.2 D16 - 单镜具名对象上限（扩展为三档）
**原决策**：≤8（GRP群演算1个，SET底板不计）固定
**新决策**：**三档可配**
- **轻量档**：≤4（访谈类简单镜头）
- **标准档**：≤8（标准剧集镜头）
- **重量档**：≤16（群戏允许，GRU群演算1个）
**应用场景**：单人访谈 / 标准剧情 / 群戏复杂场景

### 2.3 D22 - 渲染超时基准（扩展为分档）
**原决策**：单帧健康线3s固定
**新决策**：**分档健康线**
- **480p档**：2s/帧
- **720p档**：4s/帧
- **1080p档**：8s/帧
**应用场景**：低分辨率渲染 / 中等分辨率渲染 / 高分辨率渲染

### 2.4 N13 - 撤销重做步数（扩展为两档）
**原决策**：zundo快照50步固定
**新决策**：**两档可配**
- **快速档**：30步（快速模式）
- **精细档**：100步（精细模式）
**配置**：localStorage记忆用户选择

### 2.5 N21 - 图规模上限（扩展为三档）
**原决策**：单图≤60节点固定
**新决策**：**三档可配**
- **短片档**：≤30节点（短片项目）
- **标准档**：≤60节点（标准剧集项目）
- **长片档**：≤120节点（长片分章管理项目）
**应用场景**：短视频项目 / 标准剧集 / 长片分章管理

### 3.3 档位设计原则
- **2-4档为宜**：不是越多越好
- **档位间有明显差异**：如3×或10×的跨度
- **档位有清晰场景对应**：用户能判断该选哪档
- **默认档最常用**：减少用户决策负担
