### A.3 方法论：六维度 + 五风险项
- **六维度**（对每个决策点逐项审）：① 要做什么（具体任务）② 职责（谁的职责范围）③ 工具（工具链）④ 流程位置（流水线哪一步）⑤ 与其他环节关系（上下游协作）⑥ 整体关系（体系位置）。
- **五风险项（实为 6 类判定）**：
  1. **一刀切**——是否只给单一固定答案、无可选档位；
  2. **无多余选择**——是否把"分档"简化成"一个值"；
  3. **不具体**——是否含"大概/建议/可以考虑"等模糊表达；
  4. **不切实际**——理论是否脱离 v2 真身实现约束；
  5. **孤立看**——是否只看了决策点自身、未结合上下游与六维度；
  6. **矛盾**——是否与本轮/前轮或 v2 现实冲突。
- 复审表用「一刀切? / 孤立看? / 矛盾?」三列显性标注（否 / 是 / 已纠），「无多选/不具体/不切实际」并入六维度简述与各论说明。

### C.3 「无多余选择 / 不具体 / 不切实际」三项复核结论
- **无多余选择**：未发现把分档简化成单值的案例（反例均已被 P1 改造补档，如 D15/D22/N13/N21）。
