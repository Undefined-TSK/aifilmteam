## 2. 输出铁律

1. **视觉优先**：每个维度至少 **2 种不同格式**的可视化（Mermaid 图 / HTML 仪表盘 / SVG / Markdown 表格任选组合），纯文字只做补充。
2. **每个维度一个子目录**，命名严格按下方清单；文件名按原文档「必须输出」表；无明确文件名时用 `主文件.md` + `可视化.html`。
3. **HTML 规范**：单文件自包含（内嵌 CSS/JS，可引 CDN ECharts/D3），双击可开；配色统一项目色系：`#1a1a2e` `#16213e` `#0f3460` `#e94560` `#533483`。
4. **SVG 规范**：含 `<title>`/`<desc>`，节点中文。
5. **Mermaid**：用 ` ```mermaid ` 代码块；禁用 `<br>`（浏览器吞标签），用「·」分隔。
6. **中文**；**禁止 emoji**；重编号列表与表格，厌恶大段文字。
7. **数据真实性**：凡"已实测"必须给证据路径/命令回显；未实测标 `待实测`，禁止编造数值。
8. **项目个性化**：必须结合 CINEAST-3 具体上下文（白模管线、5 操作员 N1~N5、雨夜寻猫 18 镜、R5 阶段、合规债务、12GB 显存、≤100 元预算、老板铁律），禁止空泛通用建议。
9. **不改动 `体检产出\` 之外的任何文件**（只读引用项目源码）。
10. **插件引用**用 `[名称]` 占位符，名称严格来自提示词第一部分候选索引；本会话未安装的插件回退内置能力，不硬凑。
